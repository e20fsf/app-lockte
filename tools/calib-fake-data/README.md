# calib-fake-data — ข้อมูลทดสอบของโปรแกรมสอบเทียบ (ตั๋ว #210, ข้อตัดสิน Q-25)

repo นี้เป็น **public** ข้อมูลจริงของ `สอบเทียบ.accdb` (ชื่อผู้สอบเทียบ ชื่อบริษัทที่สอบเทียบ หมายเลขเครื่อง) จึงต้องไม่เข้า git — ไฟล์จริง ไฟล์จับคู่ชื่อบุคคล (`calibrator,<ชื่อ>,<รหัส>`) และผลรายงานการย้ายอยู่ใต้ `source/` (ignored) หรือนอก repo

## ฐานไหนใช้ข้อมูลอะไร
| ที่ | ข้อมูล |
|---|---|
| เทสต์อัตโนมัติ (`tests/`, ฐาน `LockteTests_*`) | ปลอมเล็ก ๆ ที่สร้างในโค้ด (`FakeCalibFile`, ข้อมูลสุ่ม) — ไม่ใช้ไฟล์ Access จริง |
| ฐานทดสอบ UAT ที่ผู้ใช้เข้าถึง (`Lockte…Uat/Test/Dev`) | ข้อมูลจริงจาก Access ได้ตามข้อตัดสินผู้ใช้ 2026-10-29 (Q-25) ด้วย `Reset-Uat.ps1 -Calib … -AllowRealCalib` เฉพาะฐานทดสอบที่ผู้ใช้รับรู้ · ไม่มี `-AllowRealCalib` ต้องเป็นไฟล์ที่ชื่อมี `fake` |
| ฐาน `Lockte` (ใช้งานจริง) | ไม่ใช้สคริปต์นี้ — ย้ายรอบสุดท้ายตามตั๋ว #235 |
| เอกสาร เทสต์ fixture คอมเมนต์ ผลรายงานที่ commit | ชื่อตัวอย่างปลอมเท่านั้น |

## ขั้นตอน
1. (ทางเลือก) ทำสำเนาปลอมสำหรับ fixture/เดโม: `python -I tools/calib-fake-data/make_fake.py "<source>\สอบเทียบ.accdb" "<source>\samples\สอบเทียบ\สอบเทียบ_fake.accdb"` — แทนชื่อผู้สอบเทียบเป็น `ผู้สอบเทียบทดสอบ n` และบริษัทเป็น `บริษัทสอบเทียบทดสอบ n` (ชื่อเดียวกันได้ชื่อปลอมเดียวกัน) คงจำนวนแถว 20/13/53/10/67/59 รหัสเครื่อง และกลุ่มข้อมูลทดสอบของการย้าย (ปีผิด 19xx/25xx/4722, หน่วยว่าง, เครื่องมือมาตรฐานผิดรูป, แผนก `DC (D02)` `BL(32,33)`, `JG-AS001-2/2560`) จบด้วย leak check ต้องได้ 0
2. โหลดเข้าฐานทดสอบ: `tools/uat/Reset-Uat.ps1 … -Calib <สำเนา .accdb> [-CalibMap <ไฟล์จับคู่>] [-JigImages <โฟลเดอร์จาก tools/calib-jig-images>] [-AllowRealCalib]` (ใช้ `--program calib` ของ `Lockte.Migration` ตั๋ว #209; ผลรายงานอยู่ใน `<Out>\calib`)
3. **ก่อน commit ทุกครั้งที่แตะเอกสาร/เทสต์/fixture ของสอบเทียบ**: `tools/calib-fake-data/Check-NoRealData.ps1 -Source "<source>\สอบเทียบ.accdb"` — อ่านชื่อที่ไม่ซ้ำจากสำเนาแล้ว `git grep` ในไฟล์ที่ track; แสดงเฉพาะจำนวน/ชื่อไฟล์ (ไม่แสดงชื่อ) exit 1 ถ้าพบ

ทั้งสามตัวไม่แก้ไฟล์ต้นทาง (ทำงานกับสำเนา) ต้องรันบน Windows ที่มี Access Database Engine (ACE) · `make_fake.py` ต้องมี Python + pywin32 (ทดสอบรันไม่ได้ในเครื่องของเซสชันที่เขียน — ยังไม่เคยรันจริง)
