## RPT-01 — ใบ SALE ORDER
ที่มา: รายงาน `ใบ sale order` ← query `พิมพืใบ sale order 1` · macro `พิมพ์ใบ sale order` ← ฟอร์ม `พิมพ์ใบ sale order`
ใครใช้ / ความถี่: ❓ Q-03 / ทุกครั้งที่รับ ORDER ใหม่ (BR-002)
พารามิเตอร์: เลขที่ ORDER (`sale oder.no`)
แหล่งข้อมูล + เงื่อนไข: T-ODD ที่ `REF_NO` = เลขที่ — ⚠ พิมพ์จาก T-ODD จึงพิมพ์ซ้ำได้เฉพาะใบที่ยังค้างส่ง (บรรทัดที่ส่งครบถูกลบแล้ว)
การจัดกลุ่ม: ไม่มี (1 ใบ)
เรียงลำดับ: `SUF_NO` ↑

## RPT-06 — สรุปการรับ ORDER
ที่มา: รายงาน `สรุปการรับORDER` ← ตารางพัก `สรุปการรับORDER` ← query `สรุปการรับORDER4`→`…53` (ฟอร์ม `วันที่ส่งออก2` ปุ่ม "พิมพ์" → macro `สรุปการรับORDER`) · รายงาน `สรุปการรับORDER1` ← `สรุปการรับORDER9` (ปุ่ม "พิมพ์สรุป ORDER มากกว่า 3000") · รายงานการรับ ORDER ตามเซลแต่ละคน / ตามชื่อลูกค้า (ฟอร์ม `วันที่ส่งออก4`, `5`)
ใครใช้ / ความถี่: ❓ Q-03 / 🔍 รายเดือน
พารามิเตอร์: ช่วงวันที่รับ ORDER (`วันที่ส่งออก.FROM_DATE`–`TO_DATE`)
แหล่งข้อมูล + เงื่อนไข: **T-ORDER (ประวัติ)** ที่ `OD_DATE` ในช่วง และ `CUS_ID`, `CUS_N` ไม่ว่าง — ORDER ที่ไม่เข้าประวัติ (BR-002 #2) ไม่ถูกนับ; ORDER ที่ลบจาก T-ODD แล้วยังถูกนับ (BR-012)
การจัดกลุ่ม: เซล (ทุกเซลใน T-เซล แสดงแม้ไม่มี ORDER)
เรียงลำดับ: รหัสเซล ↑

| หัวคอลัมน์ | ที่มา / สูตร | รูปแบบ |
|---|---|---|
| รหัส, ชื่อเซล | `SALE_ID`, `เซล.NAME` | |
| จำนวนใบORDER | จำนวน `REF_NO` ไม่ซ้ำของเซลในช่วง | จำนวนเต็ม |
| จำนวนเงิน | `Sum(AMOUNT)` ของทุกบรรทัด | ทศนิยม 2 🔍 |

ผลรวม: ท้ายรายงาน Σ จำนวนเงิน, Σ จำนวนใบ
**แบบ "มากกว่า 3000":** ต่อ**ลูกค้า** — Σ `QTY` และ Σ `AMOUNT` ในช่วง แสดงเฉพาะลูกค้าที่ **Σ จำนวนสั่ง (`QTY`) ≥ 3,000** (ไม่ใช่จำนวนเงิน)
รูปแบบผลลัพธ์: พิมพ์

## RPT-08 — สรุปการส่งออกทั้งปี (4 แบบ)
ที่มา: macro `สรุปส่งออกเดือน100/200/300/400` — ขั้นสุดท้ายเปิด **query แบบตาราง (datasheet)** `สรุปส่งออกทั้งปี` / `สรุปส่งออกทั้งปี1` / `สรุปส่งออกทั้งปี4` ไม่ใช่รายงานพิมพ์ · ตารางพัก `สรุปส่งออกเดือน10B` (ลูกค้า), `สรุปส่งออกเดือน400B` (สินค้า)
ใครใช้ / ความถี่: ❓ Q-03 / 🔍 ปลายปี
พารามิเตอร์: ช่วงวันที่ (`FROM_DATE`–`TO_DATE`) และเซล (`SELL_ID`) เฉพาะแบบ 100
แหล่งข้อมูล + เงื่อนไข: T-ODDส่งออก ที่ `DL_DATE` ในช่วง แยกเดือนด้วย `NET = 1..12` ที่เขียนลงตารางก่อน (BR-024)
การจัดกลุ่ม: ลูกค้า (แบบ 100–300) / สินค้า (แบบ 400)
เรียงลำดับ: รหัส ↑ แล้วจำนวนรวม ↓

| แบบ | ปุ่ม (ฟอร์ม) | แถวต่อ | ค่าในคอลัมน์เดือน | ขอบเขตแถว |
|---|---|---|---|---|
| 100 | "พิมพ์สรุปทั้งปี" (`วันที่ส่งออก1111`) | ลูกค้า | Σ `DL_NET` | ลูกค้าทุกรายของเซลที่เลือก (แม้ไม่มียอด) + ชื่อเซล |
| 200 | "พิมพ์สรุปทั้งปีจำนวนเงิน" (`วันที่ส่งออก10`) | ลูกค้า | Σ `DL_NET` | ลูกค้าทุกรายใน T-P_CUS |
| 300 | ปุ่มที่ 4 ของ `วันที่ส่งออก10` | ลูกค้า | Σ `DL_QTY` (จำนวน) | ลูกค้าทุกรายใน T-P_CUS |
| 400 | "สรุปทั้งปี" (`วันที่ส่งออก20`) | สินค้า | Σ `DL_QTY` และ Σ `DL_NET` แยกคอลัมน์ | สินค้าที่มีการส่ง |

| หัวคอลัมน์ | ที่มา / สูตร | รูปแบบ |
|---|---|---|
| รหัสลูกค้า / รหัสสินค้า, ชื่อ | `CUS_ID`/`CUS_N` หรือ `PD_C`/`PD_N` | |
| มกราคม … ธันวาคม | Σ ค่าของเดือนนั้น | ว่างถ้าไม่มียอด |
| จำนวนรวม (และ จำนวนเงินรวม แบบ 400) | `มกราคม + กุมภาพันธ์ + … + ธันวาคม` | ⚠ ดูด้านล่าง |
| รหัสเซล, ชื่อเซล (แบบ 100) | `P_CUS.SALE_ID`, `เซล.NAME` | |

ผลรวม: ไม่มีแถวรวมท้าย
