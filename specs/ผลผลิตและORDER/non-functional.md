## รูปแบบข้อมูล
- **วันที่:** เก็บเป็น Date/Time ค.ศ.; แสดงผล/เลขที่เอกสารใช้ พ.ศ. ตาม regional setting ของ Windows (BR-001, BR-009) · ไม่มีเวลาในข้อมูล
- **เลขเอกสาร:** ORDER `SS-YY-NNNN` (BR-001), ใบรายงานผลผลิต `LYYNNN` (BR-015), Lot `YYMMDD`(ค.ศ.)+เครื่อง+`-`+กะ+`/`+ลำดับ (BR-016), บิล `INV_NO` ข้อความ 7 หลัก (มาจากระบบออกบิลภายนอก 🔍)
- **ตัวเลข:** Double ทั้งหมด ไม่ปัดเศษ (RND-A) · เงินเป็นบาท ไม่มี VAT/ส่วนลด (BR-004)
- **ข้อความ:** ภาษาไทย (Unicode) · ชื่อลูกค้า/สินค้าถูกคัดลอกลงทุกรายการ (snapshot)
- **ค่า Yes/No / สถานะ:** ใช้ช่องข้อความ `MARK`/`MARK1` เป็นสถานะชั่วคราวระหว่าง macro (ค่าใน data-model)
- **การเรียงภาษาไทย:** ตามรหัส (เช่น `CUS_ID`, `PD_C`) ไม่ได้เรียงตามชื่อ

## Audit / Backup
- ไม่มี audit trail (ไม่มีวันที่สร้าง/แก้, ผู้แก้)
- การแก้/ลบเป็นการเขียนทับ/ลบถาวร — ยกเว้น T-ORDER ที่เป็นสำเนาตอนรับ ORDER (BR-002, BR-012)
- ไม่มี transaction — macro หยุดกลางทางทิ้งข้อมูลครึ่งทาง
- Backup: ไม่มีกลไกในโปรแกรม ❓ Q-37
