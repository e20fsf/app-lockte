# Business Rules — ผลผลิตและ ORDER

> สถานะ: ยังไม่เริ่ม — มีเฉพาะรายการ ID ที่ data-model.md อ้างถึง รายละเอียดจะเขียนตาม template

| ID | หัวข้อ | ที่มา (ระบบเดิม) |
|---|---|---|
| BR-001 | การออกเลขที่ ORDER | query `เลขที่ORDER*`, `ปรับปรุงORDER1`, ตาราง `MAX_REF_NO` |
| BR-002 | การรับ ORDER และบันทึกประวัติ | query `ปรับปรุงORDER11`, `ปรับปรุงORDER12` |
| BR-003 | การบันทึกส่งของ — ส่งครบ / ส่งไม่ครบ / ยอดค้างส่ง | query `ส่งครบORDER1..4`, `ส่งไม่ครบ*` |
| BR-004 | การคำนวณมูลค่ารายการ ส่วนลด VAT | ❓ Q-14 |
| BR-005 | การโอนผลผลิตเข้า STOCK | query `บันทึกผลผลิต2..5`, `บันทึกผลผลิต20*` |
| BR-006 | การเคลื่อนไหวสต็อกและยอดคงเหลือ | query `เบิกผลผลิต*`, `ส่งออกเข้าSTOCK*` |
| BR-007 | การตัดสต็อกสิ้นงวด / ยกยอดต้นงวด | query `ตัดSTOCK*` |
| BR-008 | การนับการใช้งานแม่พิมพ์และอายุคงเหลือ | query `บันทึกผลผลิต21`, `ตัดพิมพ์*` |
| BR-009 | การลบข้อมูลปีที่แล้ว | query `ลบข้อมูลปีที่แล้ว*`, `ลบORDERปีที่แล้ว*` |
| BR-010 | การคำนวณต้นทุนสินค้า | query `คำนวณต้นทุนG*` |
| BR-011 | การตรวจสอบวันที่ที่กรอก | ปัญหาวันที่ผิดปีใน data-model |
