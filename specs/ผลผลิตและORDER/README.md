## วัตถุประสงค์
🔍 อนุมานจากเมนูหลักและข้อมูล (❓ Q-01): ระบบงานประจำวันของโรงงานผลิตผ้าเบรก/ผ้าคลัทช์/ดิสเบรก (บจก.ล็อคเต้) ครอบคลุม
1. **รับ ORDER ลูกค้า** — ออกเลขที่ SALE ORDER ต่อเซล, พิมพ์ใบ SALE ORDER, ติดตามยอดค้างส่ง
2. **บันทึกการส่งของ** — ส่งครบ/ส่งบางส่วนต่อบรรทัด ORDER, รายงานการส่งและยอดขาย
3. **บันทึกผลผลิต 7 แผนก** — ใบรายงานผลผลิตประจำวัน (เครื่อง กะ จำนวนดี/เสีย พนักงาน แม่พิมพ์ Lot), สุ่มตรวจ QA และพิมพ์ใบตรวจตามรุ่น
4. **สต็อกและแม่พิมพ์** — โอนผลผลิตเข้าสต็อก, เบิกเพื่อผลิต, ตัดสต็อกสิ้นเดือนพร้อมมูลค่า, นับอายุการใช้งานแม่พิมพ์

## ขอบเขต
**ทำ:** (ตามเมนูที่ใช้งานอยู่ — screens.md แผนผังเมนู)
- ข้อมูลหลัก: ลูกค้า, สินค้า, เซล, แม่พิมพ์, เครื่องจักร
- ORDER: ออกเลข, บันทึก, แก้ไข/ลบ, พิมพ์ใบ SALE ORDER, รายงาน ORDER ค้างส่ง/กำหนดส่ง/สรุปการรับ
- การส่งของ: บันทึก, แก้ไข, รายงานการส่ง/สรุปยอดตามลูกค้า สินค้า เซล จังหวัด เดือน
- ผลผลิต: บันทึก 7 แผนก, แก้ไข, รายงานผลผลิต/ใบโอน, ผลผลิตประจำเดือน + % ของเสีย, ตรวจย้อนกลับ Lot
- QA: สุ่มตรวจ + ใบตรวจตามรุ่น (~290 แบบ)
- สต็อก: โอนผลผลิต, เบิก, เพิ่ม/แก้, STOCK CARD, STOCK ตามกลุ่ม, ตัดสต็อกสิ้นงวด + มูลค่า
- แม่พิมพ์: นับการใช้งาน, ตัดยอด, รายงาน
- งานประจำปี: ลบข้อมูลปีที่แล้ว (❓ Q-05)

**ไม่ทำ (Out of scope):**
- ออกบิล/ใบกำกับภาษี, บัญชีลูกหนี้, รับชำระเงิน — เลขที่บิลมาจากระบบอื่น 🔍
- วัตถุดิบ (อยู่โปรแกรม `วัตถุดิบ.accdb`), ค่าแรง/ข้อมูลพนักงานเต็ม (โปรแกรม `พนักงาน.accdb`)
- ส่วนลด, VAT (ระบบเดิมไม่มี — ❓ Q-41)
- ของที่ไม่มีทางเข้าจากเมนู จนกว่าผู้ใช้ยืนยัน (❓ Q-02, Q-07)
