# การเชื่อมต่อ — ผลผลิตและ ORDER

> สถานะ: **ถอดครบ — ไม่พบการเชื่อมต่ออัตโนมัติ** · อัปเดต 2026-10-05

**ไม่พบการเชื่อมต่ออัตโนมัติกับระบบอื่น** — หลักฐาน:
- ไม่มี linked table (INVENTORY: Linked tables = 0) — ข้อมูลทั้งหมดอยู่ในไฟล์เดียว
- macro ทั้ง 460 ตัวใช้เฉพาะ `OpenQuery`, `OpenForm`, `OpenReport`, `OpenTable`, `Close`, `MsgBox`, `Maximize`, `Quit` — ไม่มี `TransferSpreadsheet`, `TransferText`, `OutputTo`, `RunApp`
- query ไม่มี `IN '<ไฟล์อื่น>'` หรือ pass-through
- VBA ทั้ง 145 module (กู้จาก `MSysAccessStorage`) ไม่มี `TransferSpreadsheet`, `TransferText`, `OutputTo`, `SendObject`, `Shell`; Module1/Module2 ว่าง

ความเชื่อมโยงกับระบบอื่นที่เป็นการทำงานด้วยมือ (🔍):

## INT-01 — ส่งข้อมูลสรุปการส่งออกออกไปใช้ต่อ (ด้วยมือ)
ทิศทาง: ส่งออก
ระบบ/ไฟล์ปลายทาง: Excel (ตามชื่อปุ่ม — ผู้ใช้คัดลอก/ส่งออกจาก datasheet เอง)
ความถี่ / ผู้สั่งทำ: ฟอร์ม `วันที่ส่งออก20` (เมนู ส่งออกตามสินค้า) ปุ่ม "พิมพ์เพื่อส่งออกเป็น excel" → macro `สรุปส่งออก222` · macro `สรุปส่งออก1` (ตาราง `สรุปส่งออก1001`) ไม่พบปุ่มที่เรียก
รูปแบบไฟล์: ไม่มีไฟล์ — macro สร้างตาราง `สรุปส่งออก1001` / `สรุปส่งออก23` แล้วเปิดเป็น datasheet แก้ไขได้ ให้ผู้ใช้คัดลอกหรือ export จากเมนู Access

| คอลัมน์ในไฟล์ | ฟิลด์ในระบบ | การแปลงค่า |
|---|---|---|
| ตามตาราง `สรุปส่งออก1001` | ยอดส่งรวมต่อลูกค้า (`DL_QTY`, `DL_NET`) | ไม่มี |
| ตามตาราง `สรุปส่งออก23` | ยอดส่งต่อสินค้า/กลุ่ม | ไม่มี |

กรณีผิดพลาด: ไม่มีการจัดการ
