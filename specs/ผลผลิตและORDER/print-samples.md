จัดกลุ่ม: แผนก (ขีดเส้นใต้หนา) → ประเภท (เช่น "ฉีดก้ามเบรก", "ฉีดงานรับจ้าง") → แถว "รวม" ต่อประเภท + เส้นคู่ท้ายแผนก
แบบ "ตามรุ่น": ไม่มีคอลัมน์รหัส ชื่อผลผลิตเป็นชื่อรุ่น (รวมหลายรหัส)
⚠ ประเภทว่างในบางกลุ่ม (ตกแต่ง XL125 อยู่กลุ่มไม่มีชื่อ) · ตัวสะกด "ไดคาสท์" ในหัวแผนก

### RPT-10 — รายงานผลผลิตรวมแผนกไดคาสท์
หัว + ช่วงวันที่ · คอลัมน์: (ลำดับ) รหัส, ชื่อผลผลิต, จำนวน + หน่วย, นน. (น้ำหนักต่อชิ้น ทศนิยม 3), ใช้อลูมิเนียม (ทศนิยม 2) · รวมเฉพาะอลูมิเนียม
⚠ 2 รหัสไม่มีน้ำหนัก → ใช้อลูมิเนียมว่าง แต่ยังรวมยอด

### RPT-15 — การใช้งานของพิมพ์ถึงวันที่…
หัวตัวหนา + วันที่ตัดงวดในหัว · ตารางเส้นเต็ม: ที่, รหัสพิมพ์, ชื่อพิมพ์, จำนวนการใช้งาน(ครั้ง) · ไม่มีแถวรวม
⚠ วันที่ในหัว 31/12/2568 — ตัวอย่างพิมพ์ยอดถึงงวดตัดล่าสุด ไม่ใช่วันปัจจุบัน

### RPT-16 — รายงานผลผลิตประจำเดือน
เลขเอกสารขวาบน · H1 + "รายงานผลผลิตประจำเดือน <เดือน ปี>" + ช่วงวันที่ · ตารางเส้นเต็ม
คอลัมน์: แผนก, ชื่อผลผลิต, จำนวนได้, จำนวนเสีย, จำนวนรวม, %ของเสีย (ทศนิยม 3), เป้าหมาย, **ผล ("ผ่าน"/"ไม่ผ่าน" = %ของเสีย ≤ เป้าหมาย)** · แถวรวม (%ของเสีย ทศนิยม 2, เป้า 0.80)
กล่องลงนาม 2 ช่อง: ผู้จัดการฝ่ายวางแผนและควบคุมการผลิต / ผู้จัดการโรงงาน
⚠ หัวเดือน "ตุลาคม" แต่ช่วงข้อมูล ก.ย. (D-5) · คอลัมน์ "ผล" และเป้ารวม 0.80 ยังไม่อยู่ใน reports.md RPT-16

### RPT-21 — รายชื่อเครื่องจักร
หัว H3 + "หน้า x จาก y" **ขวาบน** · คอลัมน์: (ลำดับ) รหัส, ชื่อเครื่องจักร, แผนก · ไม่มีวันที่พิมพ์ ไม่มีแถวรวม
