# คำศัพท์ — ผลผลิตและ ORDER

> สถานะ: **ร่าง — รอยืนยัน** · อัปเดต 2026-10-05

| คำ | ความหมาย | ชื่อในระบบ (ตาราง/ฟิลด์) | หมายเหตุ |
|---|---|---|---|
| ORDER / SALE ORDER | ใบสั่งซื้อจากลูกค้าที่บริษัทรับ หนึ่งใบมีหลายบรรทัดสินค้า | T-ODD (ค้างส่ง), T-ORDER (ประวัติ), `REF_NO` | ใช้คำ "ORDER" — ไม่ใช่ "ใบสั่งซื้อ" ของฝ่ายจัดซื้อ |
| บรรทัด ORDER | สินค้าหนึ่งรายการในใบ ORDER | `REF_NO` + `SUF_NO` | |
| ORDER ค้างส่ง | บรรทัด ORDER ที่ยังส่งไม่ครบ | T-ODD | บรรทัดที่ส่งครบถูกลบออก |
| ยอดค้างส่ง | จำนวนที่ยังต้องส่งของบรรทัด | `ODD.QTY` (= `UND_QTY`) | หลังส่งบางส่วน `QTY` ถูกลดเป็นยอดค้าง |
| ใบ ORDER ของลูกค้า / SALE ORDER เก่า | ORDER ที่ใช้เลขของลูกค้าหรือเลขเก่า ไม่ออกเลขอัตโนมัติ | ฟอร์ม `ODD11` | BR-002 |
| ส่งออก / การส่งของ | การส่งสินค้าให้ลูกค้าตามบิล | T-ODDส่งออก | "ส่งออก" ในระบบนี้ = ส่งของให้ลูกค้า ไม่ใช่ export ต่างประเทศ |
| ส่งครบ / ส่งไม่ครบ | ผลของการส่งเทียบยอดค้าง | `MARK` = `a` / `b` | BR-003 |
| บิล | เลขที่เอกสารส่งของ/ใบกำกับ ที่อ้างในการส่ง | `INV_NO`, `INV_SUF` | 🔍 ออกจากระบบอื่น |
| กล่อง | จำนวนกล่องที่ส่ง | `DISC_PS` 🔍 | ชื่อฟิลด์เดิมแปลว่าส่วนลด แต่ไม่ใช่ ❓ Q-14 |
| เซล | เขตการขาย/พนักงานขายที่ดูแลลูกค้า | T-เซล, `SALE_ID` | 🔍 เป็นรหัสเขต ไม่ใช่ตัวคน ❓ Q-22 |
| กำหนดส่ง | วันที่ต้องส่งของบรรทัด ORDER | `DATE_DL` | |
| เครดิต | จำนวนวันชำระเงิน | `P_CUS.CREDIT`, `DUERE_D` | |
| ผลผลิต | ชิ้นงานที่แผนกผลิตได้ในหนึ่งบรรทัดใบรายงาน | T-P_REP<แผนก> | |
| ใบรายงานผลผลิต | เอกสารบันทึกผลผลิตประจำวันของแผนก | `REF_NO` รูปแบบ `LYYNNN` | ใช้เป็น "ใบโอนสินค้าระหว่างแผนก" ด้วย |
| แผนก | 7 แผนกผลิต: ไดคาสท์, ตกแต่ง, อัดผ้าเบรก, ฝนผ้าเบรก, ผ้าคลัทช์และดิสเบรก, ประกอบ, บรรจุ | T-แผนก | ในชื่อวัตถุใช้ "เบรค"/"เบรก" ปนกัน = คำเดียวกัน |
| ไดคาสท์ | ฉีดอลูมิเนียมขึ้นรูปก้ามเบรก/แผ่นคลัทช์ | | |
| ของเสีย (NG) | จำนวนชิ้นงานเสียในบรรทัดผลผลิต | `NG` | |
| จำนวนดี | ชิ้นงานดีในบรรทัดผลผลิต | `QTY` | ป้ายในฟอร์ม "จำนวนดี" |
| จำนวนรวม | ดี + เสีย = ยอดที่โอนเข้าสต็อก | `TOTAL` | BR-016, BR-005 ❓ Q-17 |
| Lot | รหัสชุดการผลิต ใช้ตรวจย้อนกลับ | `LOT`, `LOT_MTR1/2` | รูปแบบใน BR-016 |
| กะ | ช่วงเวลาทำงาน | `SHIFT` (`A`, `B`, `D`) | ❓ Q-16 |
| โอนผลผลิตเข้า STOCK | นำผลผลิตทุกแผนกในช่วงวันที่เข้าสมุดสต็อก | BR-005 | |
| STOCK / สต็อก | สมุดรายการรับ-จ่ายสินค้า (รวมงานระหว่างผลิต) | T-P_ST | |
| เบิก / ใบเบิก | การนำงานออกจากสต็อกไปผลิตต่อ | `P_ST.MARK = tr` | BR-018 |
| ตัด STOCK | ปิดงวด: ย้ายรายการไปประวัติ แล้วตั้งยอดยกมา | BR-007 | |
| ยอดยกมา / ต้นงวด | ยอดคงเหลือ ณ วันตัดสต็อก | `REF_NO = stock`, T-ต้นงวดP_ST | |
| ใบโอน | ใบรายงานผลผลิตที่ใช้เป็นใบโอนสินค้าระหว่างแผนก | RPT-10 | |
| กลุ่มสินค้า | ชุดรหัสสินค้าตาม prefix | T-รหัสสินค้าย่อ | |
| ต้นทุน (FML) | ต้นทุนต่อหน่วยที่ใช้คิดมูลค่าสต็อก | `P_NAME.FML` | BR-010 |
| แม่พิมพ์ / พิมพ์ | แม่พิมพ์ฉีด/อัด | T-รหัสพิมพ์ | "พิมพ์" ในชื่อวัตถุ = แม่พิมพ์ ไม่ใช่การพิมพ์เอกสาร (ยกเว้น `พิมพ์ใบ…`, `พิมพ์รายชื่อ…`) |
| ชอต (SHOT) | จำนวนครั้งที่แม่พิมพ์ฉีด | `QTYS`, `SHOT`, `PD_QTY` | |
| ตัด STOCK แม่พิมพ์ | ปิดงวดยอดใช้งานแม่พิมพ์ | BR-008 | |
| สุ่มตรวจ / ใบตรวจ QA | การตรวจคุณภาพ Lot ตามจำนวนสุ่ม | `MARK1 = y`, RPT-20 | |
| NCR | รายงานสินค้าไม่เป็นไปตามข้อกำหนด (Non-Conformance Report) | ตาราง `NCR` | |
| เป้าหมายคุณภาพ / QO | % ของเสียสูงสุดที่ยอมรับได้ | T-วัตถุประสงค์คุณภาพ | |
| รับจ้าง | 🔍 งานที่ผลิตให้/จ้างผู้อื่น | T-รับจ้าง | ❓ Q-11 |
| ลบข้อมูลปีที่แล้ว | งานประจำปี ลบข้อมูลเก่าเพื่อลดขนาดไฟล์ | BR-009 | |
