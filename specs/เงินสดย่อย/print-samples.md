## RPT-01 — ใบสำคัญจ่ายเงิน
**A5 แนวนอน** (ครึ่ง A4) — ✅ ตอบส่วนหนึ่งของ Q-11: ใบออกแบบให้พอดีกระดาษครึ่งแผ่น
หัว: "บริษัท ล็อคเต้ จำกัด" ตัวใหญ่กลาง + "ใบสำคัญจ่ายเงิน" + "PAYMENT VOUCHER" · "เลขที่" ขวาบน · "จ่ายโดย เงินสด" ซ้าย · "วันที่" ขวา
ตารางเส้นเต็ม **7 แถวคงที่**: (ลำดับ), รายการ, จำนวน, หน่วย, ราคา, จำนวนเงิน → แถวรวม: ตัวอักษรในวงเล็บซ้าย ("(ศูนย์บาทถ้วน)"), "รวมเงิน", ยอด
ลงนาม 4 ช่อง (เส้นทึบ + ป้ายใต้เส้น): ผู้อนุมัติ / ผู้จ่ายเงิน / สมุห์บัญชี / ผู้รับเงิน
⚠ ตัวอย่างไม่มีบรรทัดที่เลือก — พิมพ์เลข "1" ในแถวแรก, เลขที่/วันที่ว่าง, รวม 0.00 (D-6)

## RPT-02 — สรุปค่าใช้จ่ายเงินสดย่อย โรงงาน
Letter ตั้ง · หัว H1 + ชื่อรายงาน + "ตั้งแต่วันที่ <d เดือน พ.ศ.>  ถึงวันที่ …" (วันที่**แบบยาว**) · ตารางเส้นเต็ม: ลำดับที่, รายการ (TYPE), จำนวนเงิน
ท้ายตาราง: รวมค่าใช้จ่ายงวดนี้ / ค่าใช้จ่ายงวดที่แล้ว / **รวมค่าใช้จ่ายทั้งสิ้น** (ตัวหนา) → ตัวอักษรในวงเล็บใต้ตาราง
กล่องลงนาม 4 ช่อง ผู้อนุมัติ / ผู้เตรียม / ผู้ตรวจ / ผู้ลงบัญชี + "วันที่ ....../....../......" ใต้ทุกช่อง (ลำดับต่างจาก reports.md ที่ขึ้นด้วยผู้เตรียม)
ไม่มีวันที่พิมพ์และเลขหน้า
ตัวอย่างช่วงทั้งปี 2564: ประเภทซ้ำเพราะสะกดต่างกัน (`ค่าใช้จ่ายยานพาหนะ (1 ฒง 494 )` มีช่องว่างท้าย กับ `(1 ฒง 494)`) · ยอดรวมเท่ากับ "รวมทั้งหมด" ของ RPT-04 ช่วงเดียวกัน ✅

## RPT-03 — สรุปรายการเงินสดย่อยประจำเดือน
A4 ตั้ง · หัว H1 + ชื่อรายงาน · ส่วน รายรับ (ยอดยกมา, เบิกครั้งที่ 1/2, รวมรายรับ) → รายจ่าย → ยอดคงเหลือ ณ วันที่ + ตัวอักษร · วันที่พิมพ์ซ้ายล่าง
⚠ ตัวอย่างพิมพ์ **`#Type!`** ที่รวมรายรับ, ยอดคงเหลือ และตัวอักษร (D-3) และวันที่/เดือนว่างทั้งหมด — สอดคล้องกับ Q-09 (ไม่ได้ใช้ตั้งแต่ 2008)

## RPT-04 — รายการซื้อของเงินสดย่อย
A4 ตั้ง · หัวตัวหนาใหญ่ (sans) + "ตั้งแต่วันที่ … ถึงวันที่ …" (`d/m/yyyy`) · เส้นหนาใต้หัวคอลัมน์ ไม่มีเส้นแนวตั้ง
คอลัมน์: วันที่, ลำดับที่ (`mm/nn` = เลขที่ใบสำคัญจ่าย), รายการ, จำนวน (ทศนิยม 2) + หน่วย, จำนวนเงิน, ประเภท · ใบเดียวกันหลายบรรทัดซ้ำเลขลำดับที่
ท้าย: "รวมทั้งหมด Σ" + เส้นคู่ · ท้ายหน้า วันที่พิมพ์ (ยาว) ซ้าย + "หน้า x จาก y" ขวา
ตัวอย่างทั้งปี 2564 = 48 หน้า

## RPT-05 — ค่าใช้จ่ายต่างๆ
A4 ตั้ง · หัว**สีน้ำเงินเข้ม** "ค่าใช้จ่ายต่างๆ" ชิดซ้าย + หัวคอลัมน์ "รายการ" สีน้ำเงิน + เส้นสีน้ำเงิน (แบบเดียวกับรายงาน NCR ของผลผลิต) · (ลำดับ) + รายการ · ท้ายหน้า "Page x of y"
ตัวอย่าง 55 รายการ 2 หน้า (reports.md นับ 40) — มีรายการชื่อคล้ายกันหลายแบบ

## RPT-06 — ใบเสร็จรับเงินขายของเก่า
Letter ตั้ง · ไม่มีชื่อบริษัท · หัว "ใบเสร็จรับเงินขายของเก่า" ตัวหนากลาง + "เลขที่ <NO>" ขวา
บรรทัดขีดเส้นใต้: ชื่อผู้ซื้อ, วันที่ (ขวา), ที่อยู่ + โทรฯ (บรรทัดเดียวกัน)
ตารางเส้นเต็ม: (ลำดับ), รายการ, จำนวน, หน่วย, ราคา, จำนวนเงิน → "รวมทั้งหมด" ตัวหนา + ยอดในกรอบเส้นคู่ → ตัวอักษรในวงเล็บ
ลงนาม 2×2 **ที่ขอบล่างของหน้า** (ตำแหน่งคงที่): ผู้รับของ / ผู้ตรวจสอบ, ผู้รับเงิน / ผู้อนุมัติ
⚠ ที่อยู่ยาวถูกตัดชนช่องโทรฯ (D-1) · ลำดับคอลัมน์ จำนวน ก่อน หน่วย (reports.md เรียง หน่วย ก่อน จำนวน)

## RPT-07 — ใบสรุปยอดเงินขายของเก่าส่งออฟฟิส
A4 ตั้ง · วันที่พิมพ์ (ยาว) ขวาบน · หัวตัวหนา + "ตั้งแต่เลขที่ … ถึงเลขที่ …" · คอลัมน์: (ลำดับ), เลขที่, จำนวนเงิน · "รวมทั้งหมด" + เส้นคู่
⚠ ตัวอย่างไม่มีข้อมูล: ช่วงเลขที่ว่าง (✅ BR-016 "ว่างเสมอ") และแถวว่างเลข "1" (D-6)

## RPT-08 — ขายของเก่าและอื่นๆคงค้าง

## RPT-09 — รายงานยอดขายของเก่าและอื่นๆ

คอลัมน์: (ลำดับวิ่ง), วันที่, เลขที่, ลำดับ, รายการ, จำนวน, หน่วย, ราคา, จำนวนเงิน, ผู้ซื้อ · **ไม่มีหัวกลุ่มวันที่** — พิมพ์วันที่/เลขที่ทุกแถว ต่างจาก reports.md (DATE เป็นหัวกลุ่ม)
⚠ วันที่ เลขที่ และลำดับพิมพ์ชิดกันจนอ่านติดกัน (`11/1/256464001 1…`, D-1) · ท้าย "รวมทั้งหมด Σ"
