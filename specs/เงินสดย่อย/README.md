## วัตถุประสงค์
🔍 อนุมานจากเมนู ป้าย และข้อมูล (❓ Q-01): โปรแกรมของฝ่ายบัญชี/ธุรการโรงงาน บริษัท ล็อคเต้ จำกัด มี 2 งานแยกกันในไฟล์เดียว
1. **เงินสดย่อย** — บันทึกค่าใช้จ่ายที่จ่ายจากเงินสดย่อยรายบรรทัด (วันที่, เลขที่ใบสำคัญจ่าย, รายการ, จำนวน, ราคา, จำนวนเงิน, ประเภทค่าใช้จ่าย) พิมพ์ใบสำคัญจ่ายเงิน (Payment Voucher) และสรุปค่าใช้จ่ายตามประเภทเพื่อเบิกชดเชยเงินสดย่อย
2. **ขายของเก่า** — ออกใบเสร็จรับเงินขายเศษวัสดุ/ของเก่า (เลขที่อัตโนมัติ), ติดตามยอดที่ยังไม่ส่งเงินให้ออฟฟิส, พิมพ์ใบสรุปยอดส่งออฟฟิส, รายงานยอดขาย
3. **งานประจำปี** — ลบข้อมูลปีที่แล้ว (เมนูบอกให้ทำเดือน ก.พ.) และย้ายข้อมูลกลับ

## ขอบเขต
**ทำ:** (ตามเมนูที่ใช้งาน — screens.md แผนผังเมนู)
- ประเภทค่าใช้จ่าย: เพิ่ม/แก้/พิมพ์ (ลบใช้ไม่ได้ — BR-001)
- บันทึกค่าใช้จ่ายเงินสดย่อยรายวัน, แก้ไข/ลบ, พิมพ์ใบสำคัญจ่าย (BR-002…BR-005)
- รายงาน: สรุปค่าใช้จ่ายเงินสดย่อย, สรุปประจำเดือน, รายการซื้อของ (BR-006…BR-008)
- ผู้ซื้อของเก่า, รายชื่อของเก่า (BR-010)
- ใบเสร็จขายของเก่า: ออกเลขที่, บันทึก, พิมพ์ (จำนวนเงินตัวอักษร), แก้ไข/พิมพ์ซ้ำ, ลบ (ใช้ไม่ได้) (BR-011…BR-017)
- ยอดขายของเก่าค้างส่งออฟฟิส, ตัดยอด, รายงานยอดขาย (BR-016, BR-018)
- ลบข้อมูลปีที่แล้ว / ย้ายกลับ (BR-020, BR-021)

**ไม่ทำ (Out of scope):**
- การบันทึกบัญชี/สมุดรายวัน, ภาษี (VAT/หัก ณ ที่จ่าย), ใบกำกับภาษีขายของเก่า — ระบบเดิมไม่มี
- ยอดคงเหลือเงินสดย่อยแบบต่อเนื่อง — ระบบเดิมให้ผู้ใช้กรอกยอดงวดก่อนเอง (BR-006, BR-007)
- login/สิทธิ์/อนุมัติในระบบ — ระบบเดิมไม่มี (ลายเซ็นบนกระดาษ)
- การเชื่อมกับโปรแกรมอื่น (วัตถุดิบ/พนักงาน) — ไม่มี (integrations.md)
