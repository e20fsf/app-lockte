# คำศัพท์ — เงินสดย่อย

> สถานะ: ร่าง (2026-10-05)

| คำ | ความหมาย | ชื่อในระบบ (ตาราง/ฟิลด์) | หมายเหตุ |
|---|---|---|---|
| ค่าใช้จ่ายเงินสดย่อย (บรรทัด) | หนึ่งรายการที่จ่ายจากเงินสดย่อย | T-ซื้อของเงินสด (1 แถว = 1 บรรทัด) | เมนูเรียก "บันทึกค่าใช้จ่ายเงินสดย่อย" / "การซื้อของเงินสด" |
| ใบสำคัญจ่าย (Payment Voucher) | เอกสารการจ่ายเงินสด รวมหลายบรรทัดที่มีเลขที่เดียวกัน | `SUF` ของ T-ซื้อของเงินสด, RPT-01 | เลขที่รูปแบบ `MM/NN` กรอกเอง (BR-002) |
| ประเภทค่าใช้จ่าย | หมวดบัญชีค่าใช้จ่าย เช่น `ค่าขนส่ง`, `ค่าใช้จ่ายแผนกไดคาสท์` | T-ค่าใช้จ่ายต่างๆ.CASH_NAME → T-ซื้อของเงินสด.TYPE | ใช้จัดกลุ่มในสรุป (RPT-02/03) |
| ค่าใช้จ่ายงวดที่แล้ว | ยอดที่ผู้ใช้กรอกเองเพื่อบวกในสรุปค่าใช้จ่าย | T-วันที่.LAST_PAY | ❓ Q-08 ความหมาย |
| เบิกเงินสดย่อย | เงินที่ได้รับเติมเงินสดย่อย (ครั้งที่ 1, 2 ในเดือน) | T-วันที่1.RECEIVE, RECEIVE1 | RPT-03 |
| ของเก่า | เศษวัสดุ/ของใช้แล้วที่ขาย เช่น เศษเหล็ก, น้ำมันเก่า | T-รายชื่อของเก่า.NAMES | |
| ผู้ซื้อของเก่า | ผู้ซื้อ (บุคคล/บริษัท) | T-ผู้ซื้อของเก่า.NAMED | |
| ใบเสร็จขายของเก่า | ใบเสร็จรับเงินจากการขายของเก่า หลายบรรทัดต่อเลขที่ | T-ขายของเก่า (1 แถว = 1 บรรทัด), `NO` = เลขที่, `SUF` = ลำดับบรรทัด | เลขที่ `YYNNN` (BR-011) |
| ยอดค้างส่งออฟฟิส | ใบเสร็จที่เก็บเงินแล้วแต่ยังไม่ได้ส่งยอดให้สำนักงาน | T-ขายของเก่า1 | "ยอดคงค้าง" (RPT-08) |
| ตัดยอด | การสรุปใบเสร็จช่วงเลขที่หนึ่งส่งออฟฟิส แล้วเอาออกจากยอดค้าง | BR-016, RPT-07 | |
| MARK | ช่องสถานะชั่วคราว ความหมายต่างตามตาราง: `Y` = เลือกพิมพ์, `N` = กำลังตัดยอด, `del`/`DEL` = กำลังลบ | หลายตาราง | ดู business-rules state machine |
| CODE | รหัสบรรทัดใบเสร็จ = `NO` & `SUF` (เช่น `690292`) | T-ขายของเก่า.CODE | ใช้กันบรรทัดซ้ำ (BR-013) |
| ลบข้อมูลปีที่แล้ว | ลบข้อมูลค่าใช้จ่ายและขายของเก่าที่วันที่ ≤ วันที่กำหนด (สำรองไว้ในตาราง "สำเนาของ …" ก่อน) | BR-020 | ❓ Q-20 |
