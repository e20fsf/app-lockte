# Integrations — ระบบพนักงานและค่าแรง

✅ ระบบเดิม **ไม่มี** การเชื่อมต่อกับระบบภายนอกผ่านโค้ด ค้นแล้วไม่พบสิ่งต่อไปนี้:
- `TransferText`, `TransferSpreadsheet`, `OutputTo`, `SendObject`
- linked table
- ODBC หรือ pass-through query

ทุกการ "ส่งออก" คือการพิมพ์รายงานแล้วผู้ใช้นำไปดำเนินการต่อเอง

| ID | ปลายทาง | ระบบเดิมทำ | ข้อมูล | ❓ |
|---|---|---|---|---|
| INT-01 | ธนาคารทหารไทย (ttb) — โอนค่าแรง | พิมพ์รายงานรายชื่อ เลขบัญชี ยอดเงิน และหนังสือนำส่ง (RPT-05) | ACC, NAME, AMT (BR-033) | Q-03 ส่งธนาคารทางไหน (คีย์ใน internet banking / ยื่นกระดาษ / ไฟล์) ระบบใหม่ต้องสร้างไฟล์รูปแบบของธนาคารไหม |
| INT-02 | ธนาคารกสิกรไทย — โอน OT | พิมพ์รายงานพร้อมชื่ออังกฤษและคำนำหน้า (รูปแบบ K-Cash Connect? 🔍) | ACC2, TITLE, NAME ENGLISH, AMT | Q-03 |
| INT-03 | ประกันสังคม | พิมพ์ทะเบียนผู้ประกันตน (RPT-51) | ID_CODE, ชื่อ, สัญชาติ, วันเกิด, วันเริ่มงาน, ตำแหน่ง, ค่าจ้าง, วันลาออก | Q-02 ต้องยื่น สปส.1-10 / ไฟล์ e-service ไหม |
