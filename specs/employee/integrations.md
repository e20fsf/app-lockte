# Integrations — ระบบพนักงานและค่าแรง

✅ ระบบเดิม **ไม่มี** การเชื่อมต่อกับระบบภายนอกผ่านโค้ด ค้นแล้วไม่พบสิ่งต่อไปนี้:
- `TransferText`, `TransferSpreadsheet`, `OutputTo`, `SendObject`
- linked table
- ODBC หรือ pass-through query

การส่งข้อมูลออกทั้งหมดเป็นงานมือของผู้ใช้: preview รายงาน แล้ว export เป็น Excel ด้วยเมนูคลิกขวาของ Access หรือพิมพ์เป็นกระดาษ ขั้นตอนธนาคารเขียนไว้เป็นคู่มือในรายงาน `PAYROLL 1` / `PAYROLL 2` (RPT-06) ✅

## INT-01 — โอนค่าแรงเข้าธนาคารทหารไทย (ttb)
ทิศทาง: ส่งออก
ระบบ/ไฟล์ปลายทาง: TMB BUSINESS CLICK (www.sso.tmbbizdirect.com) ผ่านไฟล์ Excel template `TMB SAP_EPORTAL V3.1_NOWHT2` ที่มีปุ่ม "CREATE TEXT FILE" (template อยู่นอกโปรแกรม ❓ Q-03)
ความถี่ / ผู้สั่งทำ: ทุกงวด (วันที่จ่ายต้องเป็นวันที่ 1 หรือ 16 เท่านั้น) · "ผู้นำเข้าข้อมูล" สร้างรายการ, "ผู้อนุมัติ" อนุมัติในเว็บธนาคารด้วย OTP
รูปแบบไฟล์: export รายงาน `เงินเดือนส่งแบ็งค์ทหารไทย` เป็น Excel ไปที่ไดรฟ์ D: → คัดลอกแถวรายการ (ไม่เอาบรรทัดแรกและบรรทัดสุดท้าย) วางที่ช่อง A4 ของ template, ใส่วันที่จ่ายที่ช่อง D2 → template สร้าง text file ชื่อ "เงินเดือนพนักงาน" → นำเข้าแบบ SAPFORMAT, PAYROLL PA CODE = PA0

| คอลัมน์ในไฟล์ | ฟิลด์ในระบบ | การแปลงค่า |
|---|---|---|
| ลำดับ | running count ในรายงาน | |
| เลขบัญชี | EMPLO.ACC (ผ่านตาราง เงินเดือนส่งแบ็งค์.ACC) | ไม่แปลง (Text 10) |
| ชื่อ | ค่าแรง.NAME (ชื่อไทย) | |
| จำนวนเงิน | ค่าแรง.PAY_W (BR-033) | จำนวนเต็มบาท |

กรณีผิดพลาด: ไม่มีการตรวจในโปรแกรม — คู่มือให้ตรวจว่าเว็บธนาคารแสดงข้อมูลครบ ถ้าไม่ครบให้กลับไปทำใหม่; คนที่ไม่มีเลขบัญชี ACC จะไม่อยู่ในไฟล์โดยไม่มีคำเตือน (BR-033)
งวด 2 ช่วง (BR-008): ใช้เมนู "พิมพ์ค่าแรงส่งแบงค์ทั้ง 2 ช่วง" แทน ยอดเป็น PAY_W รวมสองช่วง

## INT-02 — โอนค่าล่วงเวลาเข้าธนาคารกสิกรไทย
ทิศทาง: ส่งออก
ระบบ/ไฟล์ปลายทาง: K-BANK BULK GATEWAY (https://ws11.kasikornbank.com/BG/BG.jsp) เมนู PAYROLL ผ่านไฟล์ Excel template `CREATE TEXT VERSION 4.0_IOS FOR PAYROLL` ปุ่ม "EXPORT TEXT FILE"
ความถี่ / ผู้สั่งทำ: ทุกงวด พร้อม INT-01 · ผู้นำเข้าข้อมูลอัปโหลด, ผู้อนุมัติอนุมัติในเว็บ (วันที่จ่าย 1 หรือ 16)
รูปแบบไฟล์: export รายงาน `เงินOTส่งแบ็งค์กสิกร` เป็น Excel ที่ไดรฟ์ D: → คัดลอกแถวรายการ (ไม่เอาบรรทัดแรกและบรรทัดสุดท้าย) วางที่ A4 ของ template, วันที่จ่ายที่ B2 → text file ชื่อ "OTกสิกร" → อัปโหลดเลือก K BANK

| คอลัมน์ในไฟล์ | ฟิลด์ในระบบ | การแปลงค่า |
|---|---|---|
| ลำดับ | running count | |
| เลขบัญชี | EMPLO.ACC2 | |
| คำนำหน้า | EMPLO.[NAME TITLE] | ⚠ มีทั้ง `Mrs` และ `Mrs.` (DQ-3) |
| ชื่อ | EMPLO.[NAME ENGLISH] | ชื่ออังกฤษ |
| จำนวนเงิน | ค่าแรง.PAY_OT (BR-033) | จำนวนเต็มบาท |

กรณีผิดพลาด: ไม่มีการตรวจในโปรแกรม; คนที่ไม่มี ACC2 หรือ PAY_OT = 0 ไม่อยู่ในไฟล์

## INT-03 — โบนัสเข้าธนาคาร
ทิศทาง: ส่งออก
ระบบ/ไฟล์ปลายทาง: เหมือน INT-01 / INT-02
ความถี่ / ผู้สั่งทำ: ปีละครั้งพร้อมงวดที่จ่ายโบนัส (เมนู 10)
รูปแบบไฟล์: รายงาน `เงินเดือนส่งแบ็งค์ทหารไทย1` (ค่าแรงงวด + โบนัส ทหารไทย) และ `เงินOTรวมโบนัสส่งแบ็งค์กสิกร` (OT + โบนัส กสิกร) — กฎยอด BR-035 · ⚠ คู่มือ RPT-06 ไม่ได้พูดถึงโบนัส ❓ Q-37

| คอลัมน์ในไฟล์ | ฟิลด์ในระบบ | การแปลงค่า |
|---|---|---|
| เลขบัญชี, ชื่อ, จำนวนเงิน | ตาราง ค่าแรงส่งแบงค์10 / PAYROLL / เงินOTส่งแบ็งค์รวมโบนัส | ผลรวมต่อเลขบัญชี (BR-035) |

กรณีผิดพลาด: ไม่มีการตรวจ — ⚠ โบนัสอาจอยู่ทั้งสองรายงาน (BR-035)
