# Glossary — ระบบพนักงานและค่าแรง

| คำ | ความหมาย | ชื่อในระบบ (ตาราง/ฟิลด์) | หมายเหตุ |
|---|---|---|---|
| พนักงาน | คนที่มีรหัสในทะเบียน ทั้งที่ทำงานอยู่และลาออกแล้ว | T-EMPLO | "ทำงานอยู่" = `RESIGN` ว่าง |
| รหัสพนักงาน | ตัวอักษรประจำแผนก + เลข 3 หลัก เช่น `D010`, `T559` | EMPLO.ID (Text 4) | เก็บเป็นตัวพิมพ์ใหญ่เสมอ (BR-050) |
| ประเภทพนักงาน (CLAS) | `1` = รายเดือน, `2` = รายวัน | EMPLO.CLAS | ในคิวรีมีอ้างถึง `3` ด้วย ❓ Q-06 |
| ค่าแรงต่อวัน | ค่าจ้างรายวัน (รายเดือนใช้ `SALARY/30`) | EMPLO.SA_DAY | |
| เงินเดือน | เงินเดือนเต็มเดือนของพนักงานรายเดือน | EMPLO.SALARY | รายวันมักเป็น 0 🔍 |
| WEEK / งวด | ช่วงคำนวณค่าแรง (ครึ่งเดือน) กำหนดด้วยวันเริ่ม/สิ้นสุด/วันจ่าย | T-ตั้งวันที่ตัดWEEK (FROM_DA, TO_DA, PAY_D) | "ตัด WEEK" = ปิดงวดค่าแรง |
| ตัด WEEK 2 ช่วง | งวดคร่อมปีใหม่ที่แยกคำนวณเป็นช่วงที่ 1 (27–31 ธ.ค.) และช่วงที่ 2 (1–11 ม.ค.) | มาโคร `คำนวณค่าแรงช่วงที่1/2` | |
| ประเภทการทำงาน | `W` ปกติ, `O1` OT วันปกติ, `S` ทำงานวันอาทิตย์, `O2` OT วันอาทิตย์, `H` ทำงานวันหยุด, `O3` OT วันหยุด | E_WORK.TYPE | |
| หน่วยเวลาทำงาน | `W` เก็บเป็น **วัน** (1 = เต็มวัน), ประเภทอื่นเก็บเป็น **ชั่วโมง** | E_WORK.WORK_T | ดู BR-001 |
| กะ | เวลาเข้า-ออกมาตรฐาน `A`–`G` | T-SHIFT, EMPLO.SHIFT | |
| วันอาทิตย์ (ตารางวันหยุดประจำสัปดาห์) | วันหยุดประจำสัปดาห์ที่ HR กรอกเป็นรายการวันที่ | T-SUNDAY | 🔍 อาจไม่ใช่วันอาทิตย์จริงเสมอ |
| วันหยุดประเพณี | วันหยุดนักขัตฤกษ์ของบริษัท | T-HOLIDAY | |
| ลา (ได้ค่าแรง/ไม่ได้ค่าแรง) | `SAL` = `Y`/`N` | LEAVE.SAL | |
| ประเภทการลา | รหัส `1`–`16` | LEAVE.SR, T-ประเภทการลางาน | ดู data-model |
| ใบเตือน | `1` วาจา, `2` หนังสือ, `3` พักงาน ≤7 วัน, `4` เลิกจ้าง | T-ใบเตือน.CODE | |
| ไม่มาทำงาน | รายชื่อคนที่ไม่ต้องสร้างเวลาปกติให้ในวันนั้น | T-NO_WORK | |
| HOT / ค่าร้อน (?) | เงินเพิ่ม 10 บาทต่อหน่วยวันทำงาน สำหรับพนักงานที่ `HOT1 = Y` | EMPLO.HOT1, ค่าแรง.HOT | ❓ Q-08 ความหมาย |
| POINT_1 | ค่าแรงต่องวดแบบกำหนดตายตัว ถ้ามีค่าจะแทนผลคำนวณ | EMPLO.POINT_1 | ❓ Q-09 |
| พนักงาน LT* | รหัสขึ้นต้น `LT` ถูกยกเว้นจากค่าแรง/โบนัส/พักร้อน | EMPLO.ID | ❓ Q-10 (ปัจจุบันไม่มีในข้อมูล) |
| ลูกค้า (งานรับจ้าง) | `Y` ยามาดะ, `S` สยามยูไนเต็ด, `L` แอล ที เวิร์ค, `P` โปรฟิวส์ — ติดป้ายเวลาทำงานเพื่อคิดค่าแรงงานรับจ้าง | T-ชื่อลูกค้า, E_WORK.MARK | ❓ Q-11 ยังใช้อยู่ไหม |
| ย้ายข้อมูล | ย้ายแถวจากตารางปัจจุบันไปตารางประวัติ (`*_ADD`) | | ดู BR-040 |
| บรรจุ | ผ่านทดลองงาน | | ดู BR-053 |
