# คิวรีของ flow: รายงานลางานเฉพาะแผนก

มาโคร: [รายงานลางานเฉพาะแผนก](<../macros.md#m-รายงานลางานเฉพาะแผนก>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-แบบสอบถาม2"></a>
## แบบสอบถาม2

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [แบบสอบถาม1](<../queries/แมโคร1.md#q-แบบสอบถาม1>)
- ใช้โดย: มาโคร [รายงานลางานเฉพาะแผนก](<../macros.md#m-รายงานลางานเฉพาะแผนก>) (OpenQuery)

```sql
SELECT EMPLO.DEPARTMENT, Count(EMPLO.ID) AS CountOfID1, แบบสอบถาม1.CountOfID, EMPLO.RESIGN
FROM แบบสอบถาม1 INNER JOIN EMPLO ON แบบสอบถาม1.DEPARTMENT = EMPLO.DEPARTMENT
GROUP BY EMPLO.DEPARTMENT, แบบสอบถาม1.CountOfID, EMPLO.RESIGN
HAVING (((EMPLO.RESIGN) Is Null));
```

## แบบสอบถาม21

- ชนิด: **SELECT** · แก้ล่าสุด 2024-07-22
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: ฟอร์ม [ประเมินผลประจำปี](<../forms/ประเมินผลประจำปี.md>) (RowSource); ฟอร์ม [ลางานทั้งแผนก](<../forms/ลางานทั้งแผนก.md>) (RowSource); ฟอร์ม [สรุปชั่วโมงการทำงาน1](<../forms/สรุปชั่วโมงการทำงาน1.md>) (RowSource); มาโคร [รายงานลางานเฉพาะแผนก](<../macros.md#m-รายงานลางานเฉพาะแผนก>) (OpenQuery)

```sql
SELECT EMPLO.DEPARTMENT, Count(EMPLO.ID) AS CountOfID
FROM EMPLO
GROUP BY EMPLO.DEPARTMENT, EMPLO.RESIGN
HAVING (((EMPLO.RESIGN) Is Null));
```

## แบบสอบถาม22

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [จำนวนพนักงาน](<../tables.md#t-จำนวนพนักงาน>)
- ใช้โดย: มาโคร [รายงานลางานเฉพาะแผนก](<../macros.md#m-รายงานลางานเฉพาะแผนก>) (OpenQuery)

```sql
INSERT INTO จำนวนพนักงาน ( QTY, DEPART )
SELECT Count(EMPLO.ID) AS CountOfID, "*" AS Expr1
FROM EMPLO
GROUP BY "*", EMPLO.RESIGN
HAVING (((EMPLO.RESIGN) Is Null));
```
