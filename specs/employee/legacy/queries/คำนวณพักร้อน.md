# คิวรีของ flow: คำนวณพักร้อน

มาโคร: [คำนวณพักร้อน](<../macros.md#m-คำนวณพักร้อน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-คำนวณพักร้อน1"></a>
## คำนวณพักร้อน1

- ชนิด: **SELECT** · แก้ล่าสุด 2022-10-31
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ลางานทั้งแผนก](<../tables.md#t-ลางานทั้งแผนก>)
- ใช้โดย: คิวรี [คำนวณพักร้อน2](<../queries/คำนวณพักร้อน.md#q-คำนวณพักร้อน2>) (SQL); มาโคร [คำนวณพักร้อน](<../macros.md#m-คำนวณพักร้อน>) (OpenQuery)

```sql
SELECT leave.SUM_D, leave.FROM_D, leave.TO_D, EMPLO.ID, [ลางานทั้งแผนก].FORM, [ลางานทั้งแผนก].TO, EMPLO.RESIGN
FROM ลางานทั้งแผนก, leave INNER JOIN EMPLO ON leave.ID = EMPLO.ID
GROUP BY leave.SUM_D, leave.FROM_D, leave.TO_D, EMPLO.ID, [ลางานทั้งแผนก].FORM, [ลางานทั้งแผนก].TO, EMPLO.RESIGN
HAVING (((leave.FROM_D)>=[Form]) AND ((leave.TO_D)<=[To]) AND ((EMPLO.ID) Not Like "lt*") AND ((EMPLO.RESIGN) Is Null));
```

<a id="q-คำนวณพักร้อน2"></a>
## คำนวณพักร้อน2

- ชนิด: **SELECT** · แก้ล่าสุด 2022-10-31
- อ่านจาก: [คำนวณพักร้อน1](<../queries/คำนวณพักร้อน.md#q-คำนวณพักร้อน1>)
- ใช้โดย: คิวรี [คำนวณพักร้อน3](<../queries/คำนวณพักร้อน.md#q-คำนวณพักร้อน3>) (SQL); มาโคร [คำนวณพักร้อน](<../macros.md#m-คำนวณพักร้อน>) (OpenQuery)

```sql
SELECT emplo.ID, emplo.RESIGN, Sum([คำนวณพักร้อน1].SUM_D) AS SumOfSUM_D
FROM emplo LEFT JOIN คำนวณพักร้อน1 ON emplo.ID = [คำนวณพักร้อน1].ID
GROUP BY emplo.ID, emplo.RESIGN
HAVING (((emplo.ID) Not Like "lt*") AND ((emplo.RESIGN) Is Null));
```

<a id="q-คำนวณพักร้อน3"></a>
## คำนวณพักร้อน3

- ชนิด: **SELECT** · แก้ล่าสุด 2022-10-31
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [คำนวณพักร้อน2](<../queries/คำนวณพักร้อน.md#q-คำนวณพักร้อน2>)
- ใช้โดย: คิวรี [คำนวณพักร้อน4](<../queries/คำนวณพักร้อน.md#q-คำนวณพักร้อน4>) (SQL); มาโคร [คำนวณพักร้อน](<../macros.md#m-คำนวณพักร้อน>) (OpenQuery)

```sql
SELECT [คำนวณพักร้อน2].ID, [คำนวณพักร้อน2].SumOfSUM_D, Format([start],'yyyy') AS Expr1, Format(Now(),'yyyy') AS Expr2, [expr2]-[expr1] AS Expr3, EMPLO.START, EMPLO.NAME
FROM คำนวณพักร้อน2 INNER JOIN EMPLO ON [คำนวณพักร้อน2].ID = EMPLO.ID
WHERE ((([คำนวณพักร้อน2].ID) Not Like "lt*") AND (([คำนวณพักร้อน2].SumOfSUM_D)<6)) OR ((([คำนวณพักร้อน2].SumOfSUM_D) Is Null));
```
