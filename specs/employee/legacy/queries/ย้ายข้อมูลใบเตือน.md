## ย้ายข้อมูลใบเตือน1

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [วันทำงาน](<../tables.md#t-วันทำงาน>), [ใบเตือน](<../tables.md#t-ใบเตือน>), [ใบเตือนADD](<../tables.md#t-ใบเตือนADD>)
- ใช้โดย: มาโคร [ย้ายข้อมูลใบเตือน](<../macros.md#m-ย้ายข้อมูลใบเตือน>) (OpenQuery)

```sql
INSERT INTO ใบเตือนADD ( [DATE], ID, NAME, DEPART, CODE, CODE_NAME, REMARK )
SELECT [ใบเตือน].Date, [ใบเตือน].ID, [ใบเตือน].NAME, [ใบเตือน].DEPART, [ใบเตือน].CODE, [ใบเตือน].CODE_NAME, [ใบเตือน].REMARK
FROM ใบเตือน, วันทำงาน
WHERE ((([ใบเตือน].Date)<=[dat]));
```

## ย้ายข้อมูลใบเตือน2

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [วันทำงาน](<../tables.md#t-วันทำงาน>), [ใบเตือน](<../tables.md#t-ใบเตือน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลใบเตือน](<../macros.md#m-ย้ายข้อมูลใบเตือน>) (OpenQuery)

```sql
UPDATE ใบเตือน, วันทำงาน SET [ใบเตือน].REMARK = "D"
WHERE ((([ใบเตือน].DATE)<=[dat]));
```
