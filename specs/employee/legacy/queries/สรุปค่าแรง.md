## สรุปค่าแรง

- ชนิด: **SELECT** · แก้ล่าสุด 2024-07-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ค่าแรง](<../tables.md#t-ค่าแรง>)
- ใช้โดย: คิวรี [สรุปค่าแรง3](<../queries/สรุปค่าแรง.md#q-สรุปค่าแรง3>) (SQL); มาโคร [คำนวณเวลาทำงาน1](<../macros.md#m-คำนวณเวลาทำงาน1>) (OpenQuery); มาโคร [สรุปค่าแรง](<../macros.md#m-สรุปค่าแรง>) (OpenQuery); มาโคร [สรุปค่าแรง1](<../macros.md#m-สรุปค่าแรง1>) (OpenQuery)

```sql
SELECT EMPLO.DEPARTMENT, Sum([ค่าแรง].PAY_W) AS SumOfPAY_W, Sum([ค่าแรง].PAY_OT) AS SumOfPAY_OT, Count(EMPLO.ID) AS CountOfID, [ค่าแรง].FROM_DATE, [ค่าแรง].TO_DATE, Sum([ค่าแรง].HOT) AS SumOfHOT, [ค่าแรง].PAY_D
FROM ค่าแรง INNER JOIN EMPLO ON [ค่าแรง].ID = EMPLO.ID
GROUP BY EMPLO.DEPARTMENT, [ค่าแรง].FROM_DATE, [ค่าแรง].TO_DATE, [ค่าแรง].PAY_D
ORDER BY EMPLO.DEPARTMENT;
```

```sql
SELECT [ค่าแรง].NAME, [PAY_W]+[PAY_OT]+[hot] AS Expr1, EMPLO.ACC, [ค่าแรง].PAY_D, EMPLO.ID
FROM EMPLO INNER JOIN ค่าแรง ON EMPLO.ID = [ค่าแรง].ID
WHERE ((([PAY_W]+[PAY_OT]+[hot])>0) AND ((EMPLO.ACC) Is Not Null));
```
