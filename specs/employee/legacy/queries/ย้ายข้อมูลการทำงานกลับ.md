# คิวรีของ flow: ย้ายข้อมูลการทำงานกลับ

มาโคร: [ย้ายข้อมูลการทำงานกลับ](<../macros.md#m-ย้ายข้อมูลการทำงานกลับ>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ย้ายข้อมูลการทำงานกลับ"></a>
## ย้ายข้อมูลการทำงานกลับ

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [ADD_EW](<../tables.md#t-ADD_EW>), [E_WORK](<../tables.md#t-E_WORK>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการทำงานกลับ](<../macros.md#m-ย้ายข้อมูลการทำงานกลับ>) (OpenQuery)

```sql
INSERT INTO E_WORK ( [DATE], ID, W_IN, W_OUT, WORK_T, TYPE, LATE, REST_T )
SELECT ADD_EW.Date, ADD_EW.ID, ADD_EW.W_IN, ADD_EW.W_OUT, ADD_EW.WORK_T, ADD_EW.TYPE, ADD_EW.LATE, ADD_EW.REST_T
FROM ADD_EW, วันทำงาน
WHERE (((ADD_EW.Date)>=[dat]));
```

## ย้ายข้อมูลการทำงานกลับ1

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [ADD_EW](<../tables.md#t-ADD_EW>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการทำงานกลับ](<../macros.md#m-ย้ายข้อมูลการทำงานกลับ>) (OpenQuery)

```sql
UPDATE วันทำงาน, ADD_EW SET ADD_EW.MARK = "y"
WHERE (((ADD_EW.DATE)>=[dat]));
```

## ย้ายข้อมูลการทำงานกลับ2

- อ่านจาก: [ADD_EW](<../tables.md#t-ADD_EW>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการทำงานกลับ](<../macros.md#m-ย้ายข้อมูลการทำงานกลับ>) (OpenQuery)
