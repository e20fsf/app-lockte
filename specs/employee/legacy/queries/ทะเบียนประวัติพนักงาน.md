## ทะเบียนประวัติพนักงาน

- ชนิด: **SELECT** · แก้ล่าสุด 2025-02-27
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: มาโคร [ทะเบียนประวัติพนักงาน](<../macros.md#m-ทะเบียนประวัติพนักงาน>) (OpenQuery); รายงาน [ทะเบียนประวัติพนักงาน](<../reports/ทะเบียนประวัติพนักงาน.md>) (RecordSource)

```sql
SELECT EMPLO.ID, EMPLO.NAME, EMPLO.BORN, EMPLO.DEPARTMENT, EMPLO.POSITION, EMPLO.PER_ADD, EMPLO.ADDRESS, EMPLO.START, EMPLO.CLAS, EMPLO.SALARY, EMPLO.SA_DAY, EMPLO.POINT, EMPLO.SEX, EMPLO.ID_S, EMPLO.ID_CODE, EMPLO.ACC, EMPLO.SHIFT, EMPLO.SECTION, EMPLO.ID_PLACE, EMPLO.ID_DATE, EMPLO.WORK, IIf([salary]=0,[sa_day],[salary]) AS Expr1, EMPLO.RESIGN, EMPLO.NATION, IIf([sex]="F","หญิง","ชาย") AS Expr2
FROM EMPLO
ORDER BY EMPLO.ID;
```
