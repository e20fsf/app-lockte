<a id="q-สรุปค่าแรงช่วงที่2"></a>
## สรุปค่าแรงช่วงที่2

- ชนิด: **SELECT** · แก้ล่าสุด 2022-09-13
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ค่าแรงช่วงที่2](<../tables.md#t-ค่าแรงช่วงที่2>)
- ใช้โดย: คิวรี [สรุปค่าแรง3ช่วงที่2](<../queries/สรุปค่าแรงช่วงที่2.md#q-สรุปค่าแรง3ช่วงที่2>) (SQL); มาโคร [สรุปค่าแรงช่วงที่2](<../macros.md#m-สรุปค่าแรงช่วงที่2>) (OpenQuery)

```sql
SELECT EMPLO.DEPARTMENT, Sum([ค่าแรงช่วงที่2].PAY_W) AS SumOfPAY_W, Sum([ค่าแรงช่วงที่2].PAY_OT) AS SumOfPAY_OT, Count(EMPLO.ID) AS CountOfID, [ค่าแรงช่วงที่2].FROM_DATE, [ค่าแรงช่วงที่2].TO_DATE, Sum([ค่าแรงช่วงที่2].HOT) AS SumOfHOT, [ค่าแรงช่วงที่2].SUNDAY, [ค่าแรงช่วงที่2].HOLIDAY
FROM EMPLO INNER JOIN ค่าแรงช่วงที่2 ON EMPLO.ID = [ค่าแรงช่วงที่2].ID
GROUP BY EMPLO.DEPARTMENT, [ค่าแรงช่วงที่2].FROM_DATE, [ค่าแรงช่วงที่2].TO_DATE, [ค่าแรงช่วงที่2].SUNDAY, [ค่าแรงช่วงที่2].HOLIDAY
ORDER BY EMPLO.DEPARTMENT;
```
