## ค่าแรงแต่ละเดือน1

- อ่านจาก: [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน](<../tables.md#t-ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน>), [สรุปค่าแรงแต่ละเดือน](<../tables.md#t-สรุปค่าแรงแต่ละเดือน>)

```sql
UPDATE ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน INNER JOIN สรุปค่าแรงแต่ละเดือน ON [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].SUF = [สรุปค่าแรงแต่ละเดือน].SUF SET [สรุปค่าแรงแต่ละเดือน].AMOUNT = Null;
```

<a id="q-ค่าแรงแต่ละเดือน3"></a>
## ค่าแรงแต่ละเดือน3

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน](<../tables.md#t-ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน>), [สำเนาของ ค่าแรง](<../tables.md#t-สำเนาของ-ค่าแรง>)
- ใช้โดย: คิวรี [ค่าแรงแต่ละเดือน4](<../queries/ค่าแรงแต่ละเดือน.md#q-ค่าแรงแต่ละเดือน4>) (SQL); มาโคร [ค่าแรงแต่ละเดือน](<../macros.md#m-ค่าแรงแต่ละเดือน>) (OpenQuery)

```sql
SELECT [สำเนาของ ค่าแรง].FROM_DATE, [สำเนาของ ค่าแรง].TO_DATE, Sum([สำเนาของ ค่าแรง].PAY_W) AS SumOfPAY_W, Sum([สำเนาของ ค่าแรง].PAY_OT) AS SumOfPAY_OT, Sum([pay_w]+[pay_ot]) AS Expr1, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].F_D, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].T_D, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].MO, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].SUF
FROM [สำเนาของ ค่าแรง], ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน
GROUP BY [สำเนาของ ค่าแรง].FROM_DATE, [สำเนาของ ค่าแรง].TO_DATE, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].F_D, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].T_D, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].MO, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].SUF
HAVING ((([สำเนาของ ค่าแรง].FROM_DATE)>=[f_d]) AND (([สำเนาของ ค่าแรง].TO_DATE)<=[t_d]));
```

## ค่าแรงแต่ละเดือน4

- ใช้โดย: มาโคร [ค่าแรงแต่ละเดือน](<../macros.md#m-ค่าแรงแต่ละเดือน>) (OpenQuery)

```sql
INSERT INTO สรุปค่าแรงแต่ละเดือน ( SUF, MO, AMOUNT )
SELECT [ค่าแรงแต่ละเดือน3].SUF, [ค่าแรงแต่ละเดือน3].MO, Sum([ค่าแรงแต่ละเดือน3].Expr1) AS SumOfExpr1

GROUP BY [ค่าแรงแต่ละเดือน3].SUF, [ค่าแรงแต่ละเดือน3].MO;
```
