# คิวรีของ flow: ขาดงาน

มาโคร: [ขาดงาน](<../macros.md#m-ขาดงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ขาดงาน2"></a>
## ขาดงาน2

- ชนิด: **SELECT** · แก้ล่าสุด 2026-01-26
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [LEAVE](<../tables.md#t-LEAVE>), [วันที่ลบการลางาน](<../tables.md#t-วันที่ลบการลางาน>)
- ใช้โดย: มาโคร [ขาดงาน](<../macros.md#m-ขาดงาน>) (OpenQuery); รายงาน [ขาดงาน2](<../reports/ขาดงาน2.md>) (RecordSource)

```sql
SELECT LEAVE.ID, LEAVE.FROM_D, LEAVE.TO_D, LEAVE.SUM_D, LEAVE.SR, EMPLO.NAME, [วันที่ลบการลางาน].DATE_F, [วันที่ลบการลางาน].DATE_T, [วันที่ลบการลางาน].EMPID
FROM วันที่ลบการลางาน, LEAVE INNER JOIN EMPLO ON LEAVE.ID = EMPLO.ID
WHERE (((LEAVE.ID) Like [EMPID]) AND ((LEAVE.FROM_D)>=[DATE_F] And (LEAVE.FROM_D)<=[DATE_T]) AND ((LEAVE.SR)="8"));
```
