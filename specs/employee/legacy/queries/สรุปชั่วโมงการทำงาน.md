# คิวรีของ flow: สรุปชั่วโมงการทำงาน

มาโคร: [สรุปชั่วโมงการทำงาน](<../macros.md#m-สรุปชั่วโมงการทำงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-สรุปชั่วโมงการทำงาน"></a>
## สรุปชั่วโมงการทำงาน

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [OT](<../tables.md#t-OT>), [สรุปชั่วโมงการทำงาน1](<../tables.md#t-สรุปชั่วโมงการทำงาน1>), [สำเนาของ ค่าแรง](<../tables.md#t-สำเนาของ-ค่าแรง>)
- ใช้โดย: คิวรี [สรุปชั่วโมงการทำงาน2](<../queries/สรุปชั่วโมงการทำงาน.md#q-สรุปชั่วโมงการทำงาน2>) (SQL); มาโคร [สรุปชั่วโมงการทำงาน](<../macros.md#m-สรุปชั่วโมงการทำงาน>) (OpenQuery)

```sql
SELECT [สำเนาของ ค่าแรง].ID, [สำเนาของ ค่าแรง].NAME, [สำเนาของ ค่าแรง].W, [สำเนาของ ค่าแรง].TT_OT, [สรุปชั่วโมงการทำงาน1].FROM_DAY, [สรุปชั่วโมงการทำงาน1].TO_DAY, [สรุปชั่วโมงการทำงาน1].MON, [สรุปชั่วโมงการทำงาน1].TT_D, [สรุปชั่วโมงการทำงาน1].DEP, [สำเนาของ ค่าแรง].FROM_DATE, [สำเนาของ ค่าแรง].TO_DATE, EMPLO.RESIGN, [สำเนาของ ค่าแรง].OT, [TT_OT]+[OT] AS Expr1
FROM สรุปชั่วโมงการทำงาน1 INNER JOIN ([สำเนาของ ค่าแรง] INNER JOIN EMPLO ON [สำเนาของ ค่าแรง].ID = EMPLO.ID) ON [สรุปชั่วโมงการทำงาน1].DEP = EMPLO.DEPARTMENT
GROUP BY [สำเนาของ ค่าแรง].ID, [สำเนาของ ค่าแรง].NAME, [สำเนาของ ค่าแรง].W, [สำเนาของ ค่าแรง].TT_OT, [สรุปชั่วโมงการทำงาน1].FROM_DAY, [สรุปชั่วโมงการทำงาน1].TO_DAY, [สรุปชั่วโมงการทำงาน1].MON, [สรุปชั่วโมงการทำงาน1].TT_D, [สรุปชั่วโมงการทำงาน1].DEP, [สำเนาของ ค่าแรง].FROM_DATE, [สำเนาของ ค่าแรง].TO_DATE, EMPLO.RESIGN, [สำเนาของ ค่าแรง].OT, [TT_OT]+[OT]
HAVING ((([สำเนาของ ค่าแรง].FROM_DATE)>=[FROM_DAY]) AND (([สำเนาของ ค่าแรง].TO_DATE)<=[TO_DAY]) AND ((EMPLO.RESIGN) Is Null));
```

<a id="q-สรุปชั่วโมงการทำงาน2"></a>
## สรุปชั่วโมงการทำงาน2

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [สรุปชั่วโมงการทำงาน](<../queries/สรุปชั่วโมงการทำงาน.md#q-สรุปชั่วโมงการทำงาน>), [สรุปชั่วโมงการทำงาน1](<../tables.md#t-สรุปชั่วโมงการทำงาน1>)
- ใช้โดย: มาโคร [สรุปชั่วโมงการทำงาน](<../macros.md#m-สรุปชั่วโมงการทำงาน>) (OpenQuery); รายงาน [สรุปชั่วโมงการทำงาน2](<../reports/สรุปชั่วโมงการทำงาน2.md>) (RecordSource)

```sql
SELECT [สรุปชั่วโมงการทำงาน].ID, EMPLO.NAME, Sum([สรุปชั่วโมงการทำงาน].W) AS SumOfW, Sum([สรุปชั่วโมงการทำงาน].TT_OT) AS SumOfTT_OT, [สรุปชั่วโมงการทำงาน1].MON, [สรุปชั่วโมงการทำงาน1].TT_D, [สรุปชั่วโมงการทำงาน1].DEP, [สรุปชั่วโมงการทำงาน1].QTY, Sum([สรุปชั่วโมงการทำงาน].OT) AS SumOfOT, Sum([สรุปชั่วโมงการทำงาน].Expr1) AS SumOfExpr1
FROM สรุปชั่วโมงการทำงาน1, สรุปชั่วโมงการทำงาน INNER JOIN EMPLO ON [สรุปชั่วโมงการทำงาน].ID = EMPLO.ID
GROUP BY [สรุปชั่วโมงการทำงาน].ID, EMPLO.NAME, [สรุปชั่วโมงการทำงาน1].MON, [สรุปชั่วโมงการทำงาน1].TT_D, [สรุปชั่วโมงการทำงาน1].DEP, [สรุปชั่วโมงการทำงาน1].QTY;
```
