## พิมพ์ใบลาออก2

- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [รหัสพนักงาน](<../tables.md#t-รหัสพนักงาน>)
- ใช้โดย: มาโคร [บันทึกพนักงานที่ลาออก](<../macros.md#m-บันทึกพนักงานที่ลาออก>) (OpenQuery)

```sql
UPDATE EMPLO INNER JOIN รหัสพนักงาน ON EMPLO.ID = [รหัสพนักงาน].ID_E SET EMPLO.RESIGN = [DATE_R], EMPLO.MEM = [RESULT];
```
