# คิวรีของ flow: ไม่มา

มาโคร: [ไม่มา](<../macros.md#m-ไม่มา>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ขออนุมัติทำOT2"></a>
## ขออนุมัติทำOT2

- ชนิด: **DELETE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [OT](<../tables.md#t-OT>)
- ใช้โดย: มาโคร [ขออนุมัติทำ OT1](<../macros.md#m-ขออนุมัติทำ-OT1>) (OpenQuery); มาโคร [ไม่มา](<../macros.md#m-ไม่มา>) (OpenQuery)

```sql
DELETE OT.*
FROM OT;
```

<a id="q-ไม่มาทำงานวันนี้1"></a>
## ไม่มาทำงานวันนี้1

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: มาโคร [ไม่มา](<../macros.md#m-ไม่มา>) (OpenQuery)

```sql
UPDATE EMPLO SET EMPLO.GRED_2 = Null
WHERE (((EMPLO.RESIGN) Is Null));
```

<a id="q-ไม่มาทำงานวันนี้2"></a>
## ไม่มาทำงานวันนี้2

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [NO_WORK1](<../tables.md#t-NO_WORK1>)
- ใช้โดย: มาโคร [ไม่มา](<../macros.md#m-ไม่มา>) (OpenQuery)

```sql
UPDATE EMPLO INNER JOIN NO_WORK1 ON EMPLO.ID = NO_WORK1.ID1 SET EMPLO.GRED_2 = "NO"
WHERE (((EMPLO.RESIGN) Is Null) AND ((EMPLO.ID)=[id1]));
```
