# คิวรีของ flow: ย้ายข้อมูลการทำงาน

มาโคร: [ย้ายข้อมูลการทำงาน](<../macros.md#m-ย้ายข้อมูลการทำงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ย้ายข้อมูลการทำงาน"></a>
## ย้ายข้อมูลการทำงาน

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [ADD_EW](<../tables.md#t-ADD_EW>), [E_WORK](<../tables.md#t-E_WORK>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการทำงาน](<../macros.md#m-ย้ายข้อมูลการทำงาน>) (OpenQuery)

```sql
INSERT INTO ADD_EW ( [DATE], ID, W_IN, W_OUT, WORK_T, TYPE, LATE, REST_T, MARK, CODE )
SELECT E_WORK.Date, E_WORK.ID, E_WORK.W_IN, E_WORK.W_OUT, E_WORK.WORK_T, E_WORK.TYPE, E_WORK.LATE, E_WORK.REST_T, E_WORK.MARK, E_WORK.CODE
FROM E_WORK, วันทำงาน
WHERE (((E_WORK.Date)<=[dat]));
```

<a id="q-ย้ายข้อมูลการทำงาน1"></a>
## ย้ายข้อมูลการทำงาน1

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [E_WORK](<../tables.md#t-E_WORK>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการทำงาน](<../macros.md#m-ย้ายข้อมูลการทำงาน>) (OpenQuery)

```sql
UPDATE E_WORK, วันทำงาน SET E_WORK.MARK = "y"
WHERE (((E_WORK.DATE)<=[dat]));
```

## ย้ายข้อมูลการทำงาน2

- ชนิด: **DELETE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [E_WORK](<../tables.md#t-E_WORK>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการทำงาน](<../macros.md#m-ย้ายข้อมูลการทำงาน>) (OpenQuery)
