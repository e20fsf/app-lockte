# คิวรีของ flow: ลบพนักงานที่ลาออกแล้ว

มาโคร: [ลบพนักงานที่ลาออกแล้ว](<../macros.md#m-ลบพนักงานที่ลาออกแล้ว>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ลบพนักงานที่ลาออกแล้ว"></a>
## ลบพนักงานที่ลาออกแล้ว

- ชนิด: **UPDATE** · แก้ล่าสุด 2023-12-27
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน](<../tables.md#t-ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน>)
- ใช้โดย: มาโคร [ลบพนักงานที่ลาออกแล้ว](<../macros.md#m-ลบพนักงานที่ลาออกแล้ว>) (OpenQuery)

```sql
UPDATE EMPLO, ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน SET EMPLO.MEM = "Y"
WHERE (((EMPLO.RESIGN)<=Date()-1095));
```

<a id="q-ลบพนักงานที่ลาออกแล้ว2"></a>
## ลบพนักงานที่ลาออกแล้ว2

- ชนิด: **DELETE** · แก้ล่าสุด 2023-12-27
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: มาโคร [ลบพนักงานที่ลาออกแล้ว](<../macros.md#m-ลบพนักงานที่ลาออกแล้ว>) (OpenQuery)

```sql
DELETE EMPLO.MEM
FROM EMPLO
WHERE (((EMPLO.MEM)="Y"));
```
