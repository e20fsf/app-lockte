# คิวรีของ flow: ไม่มาทำงาน

มาโคร: [ไม่มาทำงาน](<../macros.md#m-ไม่มาทำงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-พนักงานทั้งหมด"></a>
## พนักงานทั้งหมด

- ชนิด: **SELECT** · แก้ล่าสุด 2024-06-29
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: คิวรี [ไม่มาทำงาน1](<../queries/ไม่มาทำงาน.md#q-ไม่มาทำงาน1>) (SQL); คิวรี [ไม่มาทำงาน2](<../queries/ไม่มาทำงาน.md#q-ไม่มาทำงาน2>) (SQL); มาโคร [ไม่มาทำงาน](<../macros.md#m-ไม่มาทำงาน>) (OpenQuery)

```sql
SELECT Count(EMPLO.ID) AS CountOfID
FROM EMPLO
GROUP BY EMPLO.RESIGN
HAVING (((EMPLO.RESIGN) Is Null));
```

<a id="q-ไม่มาทำงาน3"></a>
## ไม่มาทำงาน3

- ชนิด: **DELETE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [NO_WORK1](<../tables.md#t-NO_WORK1>)

```sql
DELETE NO_WORK1.*

```

<a id="q-ไม่มาทำงาน1"></a>
## ไม่มาทำงาน1

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [NO_WORK1](<../tables.md#t-NO_WORK1>), [พนักงานทั้งหมด](<../queries/ไม่มาทำงาน.md#q-พนักงานทั้งหมด>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ไม่มาทำงาน](<../macros.md#m-ไม่มาทำงาน>) (OpenQuery)

```sql
INSERT INTO NO_WORK1 ( DATE1, ID1, NAME, DEPARTMENT, QTY, REMARK )
SELECT NO_WORK.DATE1, NO_WORK.ID1, EMPLO.NAME, EMPLO.DEPARTMENT, [พนักงานทั้งหมด].CountOfID, NO_WORK.REMARK
FROM วันทำงาน, พนักงานทั้งหมด, NO_WORK INNER JOIN EMPLO ON NO_WORK.ID1 = EMPLO.ID
WHERE (((NO_WORK.DATE1)=[DAT]) AND ((NO_WORK.W_IN)<#12/30/1899 17:0:0#));
```
