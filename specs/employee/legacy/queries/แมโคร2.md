# คิวรีของ flow: แมโคร2

มาโคร: [แมโคร2](<../macros.md#m-แมโคร2>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-แบบสอบถาม4"></a>
## แบบสอบถาม4

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [E_WORK](<../tables.md#t-E_WORK>), [SHIFT](<../tables.md#t-SHIFT>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [แมโคร2](<../macros.md#m-แมโคร2>) (OpenQuery)

```sql
INSERT INTO E_WORK ( [DATE], ID, W_IN, W_OUT, REST_T )
SELECT [วันทำงาน].DAT, EMPLO.ID, SHIFT.W_IN, SHIFT.W_OUT, SHIFT.REST_T
FROM วันทำงาน, SHIFT INNER JOIN EMPLO ON SHIFT.SHIFT = EMPLO.SHIFT
WHERE (((EMPLO.RESIGN) Is Null));
```
