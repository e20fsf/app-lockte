# คิวรีของ flow: ลบข้อมูลการลางาน

มาโคร: [ลบข้อมูลการลางาน](<../macros.md#m-ลบข้อมูลการลางาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ลบข้อมูลการลางาน"></a>
## ลบข้อมูลการลางาน

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE](<../tables.md#t-LEAVE>), [วันที่ลบการลางาน](<../tables.md#t-วันที่ลบการลางาน>)
- ใช้โดย: มาโคร [ลบข้อมูลการลางาน](<../macros.md#m-ลบข้อมูลการลางาน>) (OpenQuery)

```sql
UPDATE LEAVE, วันที่ลบการลางาน SET LEAVE.MARK = "A"
WHERE (((LEAVE.ID)=[empid]) AND ((LEAVE.FROM_D)>=[date_f] And (LEAVE.FROM_D)<=[DATE_T]));
```

<a id="q-ลบข้อมูลการลางาน1"></a>
## ลบข้อมูลการลางาน1

- ชนิด: **DELETE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE](<../tables.md#t-LEAVE>)
- ใช้โดย: มาโคร [ลบข้อมูลการลางาน](<../macros.md#m-ลบข้อมูลการลางาน>) (OpenQuery)

```sql
DELETE LEAVE.MARK
FROM LEAVE
WHERE (((LEAVE.MARK)="A"));
```
