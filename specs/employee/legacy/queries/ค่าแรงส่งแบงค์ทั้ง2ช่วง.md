## ค่าแรงส่งแบงค์ทั้ง2ช่วง1

- ชนิด: **SELECT** · แก้ล่าสุด 2025-01-13
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ตั้งวันที่ตัดWEEK](<../tables.md#t-ตั้งวันที่ตัดWEEK>), [สรุปค่าแรงช่วง1+2_4](<../queries/สรุปค่าแรงช่วง1+2.md#q-สรุปค่าแรงช่วง1+2_4>)
- ใช้โดย: คิวรี [ค่าแรงส่งแบงค์ทั้ง2ช่วง2](<../queries/ค่าแรงส่งแบงค์ทั้ง2ช่วง.md#q-ค่าแรงส่งแบงค์ทั้ง2ช่วง2>) (SQL); คิวรี [ค่าแรงส่งแบงค์ทั้ง2ช่วง3](<../queries/ค่าแรงส่งแบงค์ทั้ง2ช่วง.md#q-ค่าแรงส่งแบงค์ทั้ง2ช่วง3>) (SQL); มาโคร [ค่าแรงส่งแบงค์ทั้ง2ช่วง](<../macros.md#m-ค่าแรงส่งแบงค์ทั้ง2ช่วง>) (OpenQuery)

```sql
SELECT EMPLO.NAME, [sumofPAY_W]+[sumofPAY_OT] AS Expr1, EMPLO.ACC, EMPLO.ID, [ตั้งวันที่ตัดWEEK].PAY_D
FROM ตั้งวันที่ตัดWEEK, EMPLO INNER JOIN [สรุปค่าแรงช่วง1+2_4] ON EMPLO.ID = [สรุปค่าแรงช่วง1+2_4].ID
WHERE (((EMPLO.ACC) Is Not Null));
```

## เงินเดือนส่งแบ็งค์3

- ชนิด: **APPEND** · แก้ล่าสุด 2023-01-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [สรุปค่าแรงช่วง1+2_4](<../queries/สรุปค่าแรงช่วง1+2.md#q-สรุปค่าแรงช่วง1+2_4>), [เงินเดือนส่งแบ็งค์](<../tables.md#t-เงินเดือนส่งแบ็งค์>)
- ใช้โดย: มาโคร [ค่าแรงส่งแบงค์ทั้ง2ช่วง](<../macros.md#m-ค่าแรงส่งแบงค์ทั้ง2ช่วง>) (OpenQuery)

```sql
INSERT INTO เงินเดือนส่งแบ็งค์ ( NAM, AMT, ACC )
SELECT EMPLO.NAME, [สรุปค่าแรงช่วง1+2_4].SumOfPAY_W, EMPLO.ACC
FROM EMPLO INNER JOIN [สรุปค่าแรงช่วง1+2_4] ON EMPLO.ID = [สรุปค่าแรงช่วง1+2_4].ID
WHERE ((([สรุปค่าแรงช่วง1+2_4].SumOfPAY_W)>0) AND ((EMPLO.ACC) Is Not Null))
ORDER BY EMPLO.ACC;
```

## เงินOTส่งแบ็งค์3

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [TITLE](<../tables.md#t-TITLE>), [สรุปค่าแรงช่วง1+2_4](<../queries/สรุปค่าแรงช่วง1+2.md#q-สรุปค่าแรงช่วง1+2_4>), [เงินOTส่งแบ็งค์](<../tables.md#t-เงินOTส่งแบ็งค์>)
- ใช้โดย: มาโคร [ค่าแรงส่งแบงค์ทั้ง2ช่วง](<../macros.md#m-ค่าแรงส่งแบงค์ทั้ง2ช่วง>) (OpenQuery)

```sql
INSERT INTO เงินOTส่งแบ็งค์ ( ACC, TITLE, NAM, AMT )
SELECT EMPLO.ACC2, EMPLO.[NAME TITLE], EMPLO.[NAME ENGLISH], [สรุปค่าแรงช่วง1+2_4].SumOfPAY_OT
FROM EMPLO INNER JOIN [สรุปค่าแรงช่วง1+2_4] ON EMPLO.ID = [สรุปค่าแรงช่วง1+2_4].ID
WHERE (((EMPLO.ACC2) Is Not Null) AND (([สรุปค่าแรงช่วง1+2_4].SumOfPAY_OT)>0))
ORDER BY EMPLO.ACC2;
```
