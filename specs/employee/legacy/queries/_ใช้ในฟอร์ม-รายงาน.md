# คิวรีของ flow: _ใช้ในฟอร์ม-รายงาน

คิวรีที่ใช้เป็น RecordSource/RowSource ของฟอร์มหรือรายงาน (ไม่ได้ถูกมาโครเรียก)

<a id="q-ตกแต่ง2ทำงานยามาดะ"></a>
## ตกแต่ง2ทำงานยามาดะ

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [E_WORK](<../tables.md#t-E_WORK>)
- ใช้โดย: ฟอร์ม [วันทำงาน](<../forms/วันทำงาน.md>) (VBA)

```sql
UPDATE E_WORK SET E_WORK.MARK = "Y"
WHERE (((E_WORK.MARK) Is Null) AND ((E_WORK.ID) Like "u*"));
```

<a id="q-พิมพ์ลางานทั้งแผนก100"></a>
## พิมพ์ลางานทั้งแผนก100

- ชนิด: **SELECT** · แก้ล่าสุด 2025-01-02
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [LEAVE](<../tables.md#t-LEAVE>), [ลางานทั้งแผนก](<../tables.md#t-ลางานทั้งแผนก>)
- ใช้โดย: รายงาน [พิมพ์ลางานทั้งแผนก100](<../reports/พิมพ์ลางานทั้งแผนก100.md>) (RecordSource)

```sql
SELECT EMPLO.ID, LEAVE.FROM_D, LEAVE.FROM_T, LEAVE.TO_D, LEAVE.TO_T, LEAVE.SUM_D, LEAVE.SR, EMPLO.DEPARTMENT, [ลางานทั้งแผนก].FORM, [ลางานทั้งแผนก].TO, [ลางานทั้งแผนก].DEP, [ลางานทั้งแผนก].EMP_QTY, [ลางานทั้งแผนก].DATE_QTY, EMPLO.RESIGN, [ลางานทั้งแผนก].PAY_M, [ลางานทั้งแผนก].PAY_D, [ลางานทั้งแผนก].DATE_H, EMPLO.NAME
FROM ลางานทั้งแผนก, LEAVE INNER JOIN EMPLO ON LEAVE.ID = EMPLO.ID
WHERE (((LEAVE.FROM_D)>=[form]) AND ((LEAVE.TO_D)<=[to]) AND ((EMPLO.DEPARTMENT) Like [dep]) AND ((EMPLO.RESIGN) Is Null));
```

<a id="q-พิมพ์ใบลาออก3"></a>
## พิมพ์ใบลาออก3

- ชนิด: **SELECT** · แก้ล่าสุด 2024-07-16
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: รายงาน [พนักงานที่ลาออก](<../reports/พนักงานที่ลาออก.md>) (RecordSource)

```sql
SELECT EMPLO.ID, EMPLO.NAME, EMPLO.DEPARTMENT, EMPLO.START, EMPLO.RESIGN, EMPLO.ID_CODE, EMPLO.MEM
FROM EMPLO
WHERE (((EMPLO.RESIGN) Is Not Null));
```

<a id="q-รายชื่อเฉพาะแผนก711"></a>
## รายชื่อเฉพาะแผนก711

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [รายชื่อเฉพาะแผนก6](<../queries/พิมพ์รายชื่อเฉพาะแผนก.md#q-รายชื่อเฉพาะแผนก6>)
- ใช้โดย: รายงาน [รายชื่อเฉพาะแผนก711](<../reports/รายชื่อเฉพาะแผนก711.md>) (RecordSource)

```sql
SELECT [รายชื่อเฉพาะแผนก6].ID, [รายชื่อเฉพาะแผนก6].NAME, [รายชื่อเฉพาะแผนก6].SA_DAY, IIf([sa_day]>=300,[sa_day],300) AS Expr3, [รายชื่อเฉพาะแผนก6].POINT
FROM รายชื่อเฉพาะแผนก6
ORDER BY [รายชื่อเฉพาะแผนก6].ID;
```

<a id="q-แบบสอบถาม16"></a>
## แบบสอบถาม16

- ชนิด: **SELECT** · แก้ล่าสุด 2025-10-08
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: ฟอร์ม [EMPLO1](<../forms/EMPLO1.md>) (RowSource); ฟอร์ม [EMPLO4](<../forms/EMPLO4.md>) (RowSource)

```sql
SELECT DISTINCTROW EMPLO.ID, EMPLO.NAME, ((Now()-[BORN])/365) AS Expr1
FROM EMPLO
WHERE (((EMPLO.RESIGN) Is Null))
ORDER BY EMPLO.ID;
```
