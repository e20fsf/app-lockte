# คิวรีของ flow: พิมพ์ใบลาออก

มาโคร: [พิมพ์ใบลาออก](<../macros.md#m-พิมพ์ใบลาออก>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-พิมพ์ใบลาออก"></a>
## พิมพ์ใบลาออก

- ชนิด: **SELECT** · แก้ล่าสุด 2026-05-21
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [รหัสพนักงาน](<../tables.md#t-รหัสพนักงาน>), [แผนก](<../tables.md#t-แผนก>)
- ใช้โดย: มาโคร [พิมพ์ใบลาออก](<../macros.md#m-พิมพ์ใบลาออก>) (OpenQuery); รายงาน [พิมพ์ใบลาออก](<../reports/พิมพ์ใบลาออก.md>) (RecordSource)

```sql
SELECT EMPLO.ID, [รหัสพนักงาน].NAMES, แผนก.DEPART, EMPLO.START, [รหัสพนักงาน].ID_E, [รหัสพนักงาน].DATE_R, [รหัสพนักงาน].RESULT, แผนก.SHIFT, แผนก.SUPER, แผนก.MANAGER, แผนก.[FACTORY MANAGER]
FROM (EMPLO INNER JOIN รหัสพนักงาน ON EMPLO.ID = [รหัสพนักงาน].ID_E) INNER JOIN แผนก ON EMPLO.DEPARTMENT = แผนก.DEPART
WHERE (((EMPLO.ID)=[id_e]) And ((แผนก.SHIFT)=EMPLO.SHIFT));
```
