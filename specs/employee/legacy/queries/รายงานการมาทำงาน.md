# คิวรีของ flow: รายงานการมาทำงาน

มาโคร: [รายงานการมาทำงาน](<../macros.md#m-รายงานการมาทำงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-รายงานการมาทำงาน"></a>
## รายงานการมาทำงาน

- ชนิด: **SELECT** · แก้ล่าสุด 2022-06-10
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [E_WORK](<../tables.md#t-E_WORK>), [วันที่ลบการลางาน](<../tables.md#t-วันที่ลบการลางาน>)
- ใช้โดย: มาโคร [รายงานการมาทำงาน](<../macros.md#m-รายงานการมาทำงาน>) (OpenQuery); รายงาน [รายงานการมาทำงาน](<../reports/รายงานการมาทำงาน.md>) (RecordSource)

```sql
SELECT EMPLO.NAME, [วันที่ลบการลางาน].DATE_F, [วันที่ลบการลางาน].DATE_T, E_WORK.Date, E_WORK.W_IN, E_WORK.W_OUT, E_WORK.WORK_T, E_WORK.ID, EMPLO.DEPARTMENT
FROM วันที่ลบการลางาน, E_WORK INNER JOIN EMPLO ON E_WORK.ID = EMPLO.ID
WHERE (((E_WORK.Date)>=[date_f] And (E_WORK.Date)<=[date_t]) AND ((E_WORK.ID) Like [empid]) AND ((E_WORK.TYPE)="w"))
ORDER BY E_WORK.ID;
```
