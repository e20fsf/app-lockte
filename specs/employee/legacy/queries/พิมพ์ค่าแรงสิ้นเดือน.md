## พิมพ์ค่าแรงสิ้นเดือน4

- ชนิด: **SELECT** · แก้ล่าสุด 2024-08-27
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน](<../tables.md#t-ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน>), [สำเนาของ ค่าแรง](<../tables.md#t-สำเนาของ-ค่าแรง>)
- ใช้โดย: คิวรี [พิมพ์ค่าแรงสิ้นเดือน5](<../queries/พิมพ์ค่าแรงสิ้นเดือน.md#q-พิมพ์ค่าแรงสิ้นเดือน5>) (SQL); มาโคร [พิมพ์ค่าแรงสิ้นเดือน](<../macros.md#m-พิมพ์ค่าแรงสิ้นเดือน>) (OpenQuery); มาโคร [พิมพ์ค่าแรงสิ้นเดือน3](<../macros.md#m-พิมพ์ค่าแรงสิ้นเดือน3>) (OpenQuery)

```sql
SELECT [สำเนาของ ค่าแรง].ID, [สำเนาของ ค่าแรง].NAME, [สำเนาของ ค่าแรง].W, [สำเนาของ ค่าแรง].PAY_W, [สำเนาของ ค่าแรง].FROM_DATE, EMPLO.ID_CODE, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].F_D, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].T_D, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].MO, [สำเนาของ ค่าแรง].TO_DATE, [สำเนาของ ค่าแรง].TT_OT, EMPLO.DEPARTMENT, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].DEP, [สำเนาของ ค่าแรง].PAY_OT, EMPLO.GRED_1
FROM ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน, EMPLO INNER JOIN [สำเนาของ ค่าแรง] ON EMPLO.ID = [สำเนาของ ค่าแรง].ID
GROUP BY [สำเนาของ ค่าแรง].ID, [สำเนาของ ค่าแรง].NAME, [สำเนาของ ค่าแรง].W, [สำเนาของ ค่าแรง].PAY_W, [สำเนาของ ค่าแรง].FROM_DATE, EMPLO.ID_CODE, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].F_D, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].T_D, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].MO, [สำเนาของ ค่าแรง].TO_DATE, [สำเนาของ ค่าแรง].TT_OT, EMPLO.DEPARTMENT, [ตั้งวันที่พิมพ์ค่าแรงสิ้นเดือน].DEP, [สำเนาของ ค่าแรง].PAY_OT, EMPLO.GRED_1
HAVING ((([สำเนาของ ค่าแรง].TO_DATE)>=[f_d] And ([สำเนาของ ค่าแรง].TO_DATE)<=[t_d]) AND ((EMPLO.DEPARTMENT) Like [dep]) AND ((EMPLO.GRED_1) Is Null))
ORDER BY [สำเนาของ ค่าแรง].ID;
```

## พิมพ์ค่าแรงสิ้นเดือน5

- ชนิด: **SELECT** · แก้ล่าสุด 2024-08-27
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [พิมพ์ค่าแรงสิ้นเดือน4](<../queries/พิมพ์ค่าแรงสิ้นเดือน.md#q-พิมพ์ค่าแรงสิ้นเดือน4>)
- ใช้โดย: คิวรี [พิมพ์ค่าแรงสิ้นเดือน6](<../queries/พิมพ์ค่าแรงสิ้นเดือน.md#q-พิมพ์ค่าแรงสิ้นเดือน6>) (SQL); มาโคร [พิมพ์ค่าแรงสิ้นเดือน](<../macros.md#m-พิมพ์ค่าแรงสิ้นเดือน>) (OpenQuery); มาโคร [พิมพ์ค่าแรงสิ้นเดือน3](<../macros.md#m-พิมพ์ค่าแรงสิ้นเดือน3>) (OpenQuery); รายงาน [พิมพ์ค่าแรงสิ้นเดือน 9](<../reports/พิมพ์ค่าแรงสิ้นเดือน 9.md>) (RecordSource); รายงาน [พิมพ์ค่าแรงสิ้นเดือน10](<../reports/พิมพ์ค่าแรงสิ้นเดือน10.md>) (RecordSource)

```sql
SELECT [พิมพ์ค่าแรงสิ้นเดือน4].ID, EMPLO.NAME, Sum([พิมพ์ค่าแรงสิ้นเดือน4].W) AS SumOfW, Sum([พิมพ์ค่าแรงสิ้นเดือน4].PAY_W) AS SumOfPAY_W, [พิมพ์ค่าแรงสิ้นเดือน4].ID_CODE, [พิมพ์ค่าแรงสิ้นเดือน4].MO, EMPLO.SALARY, EMPLO.SA_DAY, EMPLO.CLAS, IIf([clas]<>"1",[sa_day],[salary]) AS Expr1, EMPLO.DEPARTMENT, [พิมพ์ค่าแรงสิ้นเดือน4].DEP, IIf([dep]="*","ทั้งหมด",[dep]) AS Expr2, Sum([พิมพ์ค่าแรงสิ้นเดือน4].PAY_OT) AS SumOfPAY_OT
FROM พิมพ์ค่าแรงสิ้นเดือน4 INNER JOIN EMPLO ON [พิมพ์ค่าแรงสิ้นเดือน4].ID = EMPLO.ID
GROUP BY [พิมพ์ค่าแรงสิ้นเดือน4].ID, EMPLO.NAME, [พิมพ์ค่าแรงสิ้นเดือน4].ID_CODE, [พิมพ์ค่าแรงสิ้นเดือน4].MO, EMPLO.SALARY, EMPLO.SA_DAY, EMPLO.CLAS, IIf([clas]<>"1",[sa_day],[salary]), EMPLO.DEPARTMENT, [พิมพ์ค่าแรงสิ้นเดือน4].DEP, IIf([dep]="*","ทั้งหมด",[dep]);
```
