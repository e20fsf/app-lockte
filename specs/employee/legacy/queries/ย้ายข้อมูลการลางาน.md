# คิวรีของ flow: ย้ายข้อมูลการลางาน

มาโคร: [ย้ายข้อมูลการลางาน](<../macros.md#m-ย้ายข้อมูลการลางาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ย้ายข้อมูลวันลา1"></a>
## ย้ายข้อมูลวันลา1

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE_ADD](<../tables.md#t-LEAVE_ADD>), [PAY](<../tables.md#t-PAY>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการลางาน](<../macros.md#m-ย้ายข้อมูลการลางาน>) (OpenQuery)

```sql
INSERT INTO LEAVE_ADD ( [DATE], ID, FROM_D, FROM_T, TO_D, TO_T, SUM_D, SR, SAL, REMARK, MARK, SALA_DAY, PAY )
SELECT LEAVE.Date, LEAVE.ID, LEAVE.FROM_D, LEAVE.FROM_T, LEAVE.TO_D, LEAVE.TO_T, LEAVE.SUM_D, LEAVE.SR, LEAVE.SAL, LEAVE.REMARK, LEAVE.MARK, LEAVE.SALA_DAY, LEAVE.PAY
FROM LEAVE, วันทำงาน
WHERE (((LEAVE.TO_D)<=[dat]));
```

<a id="q-ย้ายข้อมูลวันลา2"></a>
## ย้ายข้อมูลวันลา2

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE](<../tables.md#t-LEAVE>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการลางาน](<../macros.md#m-ย้ายข้อมูลการลางาน>) (OpenQuery)

```sql
UPDATE LEAVE, วันทำงาน SET LEAVE.MARK = "Y"
WHERE (((LEAVE.TO_D)<=[dat]));
```

<a id="q-ย้ายข้อมูลวันลา3"></a>
## ย้ายข้อมูลวันลา3

- ชนิด: **DELETE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE](<../tables.md#t-LEAVE>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการลางาน](<../macros.md#m-ย้ายข้อมูลการลางาน>) (OpenQuery)

```sql
DELETE LEAVE.Date, LEAVE.ID, LEAVE.FROM_D, LEAVE.FROM_T, LEAVE.TO_D, LEAVE.TO_T, LEAVE.SUM_D, LEAVE.SR, LEAVE.SAL, LEAVE.REMARK, LEAVE.MARK
FROM LEAVE
WHERE (((LEAVE.MARK)="Y"));
```
