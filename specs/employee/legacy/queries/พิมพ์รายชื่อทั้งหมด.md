มาโคร: [พิมพ์รายชื่อทั้งหมด](<../macros.md#m-พิมพ์รายชื่อทั้งหมด>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-พิมพ์รายชื่อทั้งหมด"></a>
## พิมพ์รายชื่อทั้งหมด

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [เพศพนักงานทั้งหมด1](<../queries/พิมพ์รายชื่อทั้งหมด.md#q-เพศพนักงานทั้งหมด1>)
- ใช้โดย: มาโคร [พิมพ์รายชื่อทั้งหมด](<../macros.md#m-พิมพ์รายชื่อทั้งหมด>) (OpenQuery); รายงาน [EMPLO](<../reports/EMPLO.md>) (RecordSource)

```sql
SELECT EMPLO.ID, EMPLO.NAME, EMPLO.BORN, EMPLO.DEPARTMENT, EMPLO.POSITION, EMPLO.START, EMPLO.CLAS, EMPLO.RESIGN, [เพศพนักงานทั้งหมด1].SumOfSumOfM, [เพศพนักงานทั้งหมด1].SumOfSumOfF, EMPLO.HOSPITAL, EMPLO.SALARY, EMPLO.SA_DAY
FROM EMPLO, เพศพนักงานทั้งหมด1
WHERE (((EMPLO.RESIGN) Is Null));
```

<a id="q-เพศพนักงานทั้งหมด1"></a>
## เพศพนักงานทั้งหมด1

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [เพศพนักงานทั้งหมด](<../queries/แมโคร1.md#q-เพศพนักงานทั้งหมด>)
- ใช้โดย: คิวรี [พิมพ์รายชื่อทั้งหมด](<../queries/พิมพ์รายชื่อทั้งหมด.md#q-พิมพ์รายชื่อทั้งหมด>) (SQL)

```sql
SELECT Sum([เพศพนักงานทั้งหมด].SumOfM) AS SumOfSumOfM, Sum([เพศพนักงานทั้งหมด].SumOfF) AS SumOfSumOfF
FROM เพศพนักงานทั้งหมด;
```
