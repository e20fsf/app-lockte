# คิวรีของ flow: รวมค่าแรง

มาโคร: [รวมค่าแรง](<../macros.md#m-รวมค่าแรง>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-รวมค่าแรง1"></a>
## รวมค่าแรง1

- ชนิด: **SELECT** · แก้ล่าสุด 2024-11-13
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน](<../tables.md#t-ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน>), [สำเนาของ ค่าแรง](<../tables.md#t-สำเนาของ-ค่าแรง>)
- ใช้โดย: คิวรี [รวมค่าแรง2](<../queries/รวมค่าแรง.md#q-รวมค่าแรง2>) (SQL); มาโคร [รวมค่าแรง](<../macros.md#m-รวมค่าแรง>) (OpenQuery)

```sql
SELECT EMPLO.DEPARTMENT, [สำเนาของ ค่าแรง].PAY_W, [สำเนาของ ค่าแรง].PAY_OT, [สำเนาของ ค่าแรง].FROM_DATE, [สำเนาของ ค่าแรง].TO_DATE, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].F_D, [ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน].T_D
FROM ตั้งวันที่พิมพ์ค่าแรงแต่ละเดือน, [สำเนาของ ค่าแรง] INNER JOIN EMPLO ON [สำเนาของ ค่าแรง].ID = EMPLO.ID
WHERE ((([สำเนาของ ค่าแรง].FROM_DATE)>=[f_d]) AND (([สำเนาของ ค่าแรง].TO_DATE)<=[t_d]));
```

<a id="q-รวมค่าแรง2"></a>
## รวมค่าแรง2

- ชนิด: **SELECT** · แก้ล่าสุด 2024-11-13
- อ่านจาก: [รวมค่าแรง1](<../queries/รวมค่าแรง.md#q-รวมค่าแรง1>)
- ใช้โดย: มาโคร [รวมค่าแรง](<../macros.md#m-รวมค่าแรง>) (OpenQuery); รายงาน [รวมค่าแรง](<../reports/รวมค่าแรง.md>) (RecordSource)

```sql
SELECT [รวมค่าแรง1].DEPARTMENT, Sum([รวมค่าแรง1].PAY_W) AS SumOfPAY_W, Sum([รวมค่าแรง1].PAY_OT) AS SumOfPAY_OT, Sum([pay_w]+[pay_ot]) AS Expr1, [รวมค่าแรง1].F_D, [รวมค่าแรง1].T_D
FROM รวมค่าแรง1
GROUP BY [รวมค่าแรง1].DEPARTMENT, [รวมค่าแรง1].F_D, [รวมค่าแรง1].T_D;
```
