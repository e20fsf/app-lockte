<a id="q-ย้ายข้อมูลการลางานกลับ"></a>
## ย้ายข้อมูลการลางานกลับ

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE_ADD](<../tables.md#t-LEAVE_ADD>), [PAY](<../tables.md#t-PAY>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการลางานกลับ](<../macros.md#m-ย้ายข้อมูลการลางานกลับ>) (OpenQuery)

```sql
INSERT INTO LEAVE ( [DATE], ID, FROM_D, TO_D, FROM_T, TO_T, SUM_D, SR, SAL, REMARK, MARK, SALA_DAY, PAY, CODE_A )
SELECT LEAVE_ADD.Date, LEAVE_ADD.ID, LEAVE_ADD.FROM_D, LEAVE_ADD.TO_D, LEAVE_ADD.FROM_T, LEAVE_ADD.TO_T, LEAVE_ADD.SUM_D, LEAVE_ADD.SR, LEAVE_ADD.SAL, LEAVE_ADD.REMARK, LEAVE_ADD.MARK, LEAVE_ADD.SALA_DAY, LEAVE_ADD.PAY, LEAVE_ADD.CODE_A
FROM วันทำงาน, LEAVE_ADD
WHERE (((LEAVE_ADD.FROM_D)>=[dat]));
```

## ย้ายข้อมูลการลางานกลับ1

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [LEAVE_ADD](<../tables.md#t-LEAVE_ADD>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ย้ายข้อมูลการลางานกลับ](<../macros.md#m-ย้ายข้อมูลการลางานกลับ>) (OpenQuery)

```sql
UPDATE วันทำงาน, LEAVE_ADD SET LEAVE_ADD.MARK = "y"
WHERE (((LEAVE_ADD.FROM_D)>=[dat]));
```
