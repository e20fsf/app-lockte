มาโคร: [การประเมินผลพนักงาน](<../macros.md#m-การประเมินผลพนักงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-การประเมินผลพนักงาน"></a>
## การประเมินผลพนักงาน

- ชนิด: **SELECT** · แก้ล่าสุด 2025-07-14
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>)
- ใช้โดย: มาโคร [การประเมินผลพนักงาน](<../macros.md#m-การประเมินผลพนักงาน>) (OpenQuery); รายงาน [การประเมินผลพนักงาน](<../reports/การประเมินผลพนักงาน.md>) (RecordSource)

```sql
SELECT EMPLO.ID, EMPLO.NAME, EMPLO.DEPARTMENT, EMPLO.POSITION, EMPLO.START, EMPLO.CLAS, EMPLO.POINT, EMPLO.SHIFT, EMPLO.DATE_1, EMPLO.DATE_2, EMPLO.POINT_1, EMPLO.POINT_2, EMPLO.DATE_3, EMPLO.GRED_1, EMPLO.GRED_2, EMPLO.RESIGN, EMPLO.MEM
FROM EMPLO
WHERE (((EMPLO.DATE_1) Is Not Null) AND ((EMPLO.RESIGN) Is Null));
```
