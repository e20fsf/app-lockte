# คิวรีของ flow: ลบข้อมูลการทำงาน

มาโคร: [ลบข้อมูลการทำงาน](<../macros.md#m-ลบข้อมูลการทำงาน>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-ลบข้อมูลการทำงาน"></a>
## ลบข้อมูลการทำงาน

- ชนิด: **UPDATE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [E_WORK](<../tables.md#t-E_WORK>), [วันทำงาน](<../tables.md#t-วันทำงาน>)
- ใช้โดย: มาโคร [ลบข้อมูลการทำงาน](<../macros.md#m-ลบข้อมูลการทำงาน>) (OpenQuery)

```sql
UPDATE E_WORK, วันทำงาน SET E_WORK.MARK = "Y"
WHERE (((E_WORK.DATE)=[dat]) And ((E_WORK.TYPE)="W") And ((E_WORK.ID)=[วันทำงาน].code));
```

<a id="q-ลบข้อมูลการทำงาน1"></a>
## ลบข้อมูลการทำงาน1

- ชนิด: **DELETE** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [E_WORK](<../tables.md#t-E_WORK>)
- ใช้โดย: มาโคร [ลบข้อมูลการทำงาน](<../macros.md#m-ลบข้อมูลการทำงาน>) (OpenQuery); มาโคร [ลบข้อมูลการทำงาน333](<../macros.md#m-ลบข้อมูลการทำงาน333>) (OpenQuery); มาโคร [ลบข้อมูลการทำงานOT](<../macros.md#m-ลบข้อมูลการทำงานOT>) (OpenQuery); มาโคร [ลบข้อมูลการทำงานOT333](<../macros.md#m-ลบข้อมูลการทำงานOT333>) (OpenQuery)

```sql
DELETE E_WORK.MARK
FROM E_WORK
WHERE (((E_WORK.MARK)="Y"));
```
