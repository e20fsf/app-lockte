# คิวรีของ flow: คำนวณเวลาทำงาน1

มาโคร: [คำนวณเวลาทำงาน1](<../macros.md#m-คำนวณเวลาทำงาน1>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-คำนวณเวลาทำงาน30"></a>
## คำนวณเวลาทำงาน30

- ชนิด: **SELECT** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [E_WORK](<../tables.md#t-E_WORK>), [ตั้งวันที่ตัดWEEK](<../tables.md#t-ตั้งวันที่ตัดWEEK>)
- ใช้โดย: คิวรี [คำนวณเวลาทำงาน100](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน100>) (SQL); คิวรี [คำนวณเวลาทำงาน50](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน50>) (SQL); คิวรี [คำนวณเวลาทำงาน60](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน60>) (SQL); คิวรี [คำนวณเวลาทำงาน70](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน70>) (SQL); คิวรี [คำนวณเวลาทำงาน80](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน80>) (SQL); คิวรี [คำนวณเวลาทำงาน90](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน90>) (SQL); มาโคร [คำนวณเวลาทำงาน1](<../macros.md#m-คำนวณเวลาทำงาน1>) (OpenQuery)

```sql
SELECT E_WORK.Date, E_WORK.ID, E_WORK.W_IN, E_WORK.W_OUT, E_WORK.REST_T, E_WORK.WORK_T, E_WORK.TYPE, E_WORK.LATE, [ตั้งวันที่ตัดWEEK].FROM_DA, [ตั้งวันที่ตัดWEEK].TO_DA, [ตั้งวันที่ตัดWEEK].PAY_D, [ตั้งวันที่ตัดWEEK].CUS, E_WORK.MARK
FROM E_WORK, ตั้งวันที่ตัดWEEK
GROUP BY E_WORK.Date, E_WORK.ID, E_WORK.W_IN, E_WORK.W_OUT, E_WORK.REST_T, E_WORK.WORK_T, E_WORK.TYPE, E_WORK.LATE, [ตั้งวันที่ตัดWEEK].FROM_DA, [ตั้งวันที่ตัดWEEK].TO_DA, [ตั้งวันที่ตัดWEEK].PAY_D, [ตั้งวันที่ตัดWEEK].CUS, E_WORK.MARK
HAVING (((E_WORK.Date)>=[from_da] And (E_WORK.Date)<=[to_da]) AND ((E_WORK.MARK)=[CUS]));
```

## คำนวณเวลาทำงาน50

- ชนิด: **APPEND** · แก้ล่าสุด 2021-05-12
- อ่านจาก: [คำนวณเวลาทำงาน30](<../queries/คำนวณเวลาทำงาน1.md#q-คำนวณเวลาทำงาน30>)
- ใช้โดย: มาโคร [คำนวณเวลาทำงาน1](<../macros.md#m-คำนวณเวลาทำงาน1>) (OpenQuery)

```sql

SELECT [คำนวณเวลาทำงาน30].ID, Sum([คำนวณเวลาทำงาน30].WORK_T) AS SumOfWORK_T
FROM คำนวณเวลาทำงาน30
GROUP BY [คำนวณเวลาทำงาน30].ID, [คำนวณเวลาทำงาน30].TYPE
HAVING ((([คำนวณเวลาทำงาน30].TYPE)="w"));
```
