# คิวรีของ flow: มาสาย1

มาโคร: [มาสาย1](<../macros.md#m-มาสาย1>) — ลำดับคิวรีตามขั้นตอนของมาโคร (รวมคิวรี SELECT ที่ถูกอ้างถึง)

<a id="q-มาสาย"></a>
## มาสาย

- ชนิด: **SELECT** · แก้ล่าสุด 2024-06-14
- อ่านจาก: [EMPLO](<../tables.md#t-EMPLO>), [E_WORK](<../tables.md#t-E_WORK>), [วันที่ลบการลางาน](<../tables.md#t-วันที่ลบการลางาน>)
- ใช้โดย: มาโคร [มาสาย1](<../macros.md#m-มาสาย1>) (OpenQuery); รายงาน [มาสาย1](<../reports/มาสาย1.md>) (RecordSource)

```sql
SELECT E_WORK.Date, E_WORK.ID, E_WORK.W_IN, E_WORK.LATE, EMPLO.NAME, [วันที่ลบการลางาน].DATE_F, [วันที่ลบการลางาน].DATE_T, [วันที่ลบการลางาน].EMPID
FROM วันที่ลบการลางาน, E_WORK INNER JOIN EMPLO ON E_WORK.ID = EMPLO.ID
WHERE (((E_WORK.Date)>=[DATE_F] And (E_WORK.Date)<=[DATE_T]) AND ((E_WORK.ID) Like [EMPID]) AND ((E_WORK.LATE) Is Not Null));
```
