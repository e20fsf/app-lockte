## รายงานรอบค่าแรง (lot 2)

### RPT-01 — คำนวณเวลาทำงาน
หัว H1 ฟอนต์ Cordia: "บริษัท ล็อคเต้ จำกัด" / "คำนวณเวลาทำงาน" + "ตั้งแต่วันที่ … ถึงวันที่ …" + แถบ "วันอาทิตย์ n วัน  วันหยุด n วัน  วันทำงาน n วัน  รวมทั้งหมด n วัน"
คอลัมน์: (ลำดับ) รหัส, ชื่อ-นามสกุล, วันปกติ, วันลา, OTวันปกติ, วันอาทิตย์, OTวันอาทิตย์, วันหยุด, OTวันหยุด (ทศนิยม 2 ทุกช่อง) · ท้ายหน้ามาตรฐาน
ท้ายรายงาน: "รวม n คน" + เส้นคู่ — นับคนอย่างเดียว ไม่รวมคอลัมน์ (✅ หน้าสุดท้ายของ `คำนวณเวลาทำงาน13` ใน lot 3)

### RPT-02 — ค่าแรงงวดวันที่ … แผนก …
หัว H1 Cordia + "ค่าแรงงวดวันที่ <TO_DATE>  แผนก<ชื่อ>"
คอลัมน์: (ลำดับ) รหัส, ชื่อ-นามสกุล, ค่าแรง (อัตรา ทศนิยม 2), วันทำงาน, วันลา, OTปกติ, วันหยุด, ค่าแรง, ค่าล่วงเวลา, ยอดรวม (จำนวนเต็ม), **ผู้รับเงิน (เส้นให้เซ็น)**
ท้าย: "รวม n คน" + ผลรวมทุกคอลัมน์ + เส้นคู่
⚠ คนรายเดือน: อัตรา 15,000.00 แต่ "วันทำงาน 1.00" และค่าแรง 7,500 (ครึ่งเดือน) — วันทำงานของรายเดือนไม่ใช่จำนวนวันจริง (BR-003)

### RPT-03 — ค่าแรงพนักงาน (สรุปรายแผนก)
หัว H1 + "ค่าแรงพนักงาน" + วันที่พิมพ์ `d/m/yyyy` ขวา + "ตั้งแต่วันที่ … ถึงวันที่ … วันที่จ่าย …" + "วันอาทิตย์ n วัน วันหยุด n วัน วันทำงาน n วัน รวม n วัน คิดค่าแรง n วัน"
คอลัมน์: (ลำดับ) แผนก, จำนวนพนักงาน, ค่าแรง, ค่าล่วงเวลา, รวม, %ค่าล่วงเวลา (ทศนิยม 2) · แถวรวม + เส้นคู่
ลงนาม (เส้นทึบ): บุคคล / ผู้จัดการโรงงาน / สมุห์บัญชี และแถวล่าง **กรรมการผู้จัดการ**
⚠ ไม่เห็น "จำนวนรายการโอน / ค่าธรรมเนียม" ที่ reports.md RPT-03 ระบุไว้ในหัวรายงาน 🔍 · กรรมการผู้จัดการยังไม่อยู่ในสเปค

### RPT-04 — สลิปเงินเดือน (รายละเอียดการจ่ายค่าแรงงวดวันที่ …)
**3 ใบต่อหน้า A4 ตั้ง** (ตัดแบ่งได้) — 34 หน้า ≈ 100 คน
หัว H5: โลโก้บริษัทซ้าย + "บริษัท ล็อคเต้ จำกัด" + ที่อยู่ "85/36 ซ.สุขาภิบาล2 ถ.พุทธมณฑลสาย5 ต.อ้อมน้อย อ.กระทุ่มแบน จ.สมุทรสาคร โทร•024204554" + "รายละเอียดการจ่ายค่าแรงงวดวันที่ <วันจ่าย>"
แถบหัว: ตั้งแต่วันที่, ถึงวันที่, จำนวน n วัน, วันอาทิตย์ n วัน, วันหยุด n วัน, วันทำงาน n วัน · รหัสพนักงาน, ชื่อ-นามสกุล, ค่าแรงเดือนละหรือวันละ
ตารางเส้นเต็ม 2 ส่วน:
- **เวลาทำงาน** 7 ช่อง: วันปกติ, วันลา, วันอาทิตย์, วันหยุด, OTปกติ, OTวันอาทิตย์, OTวันหยุด (ทศนิยม 1)
- **ค่าแรง** 6 ช่อง: วันปกติ, วันอาทิตย์, วันหยุด, OTปกติ, OTวันอาทิตย์, OTวันหยุด (จำนวนเต็ม)
- แถวล่าง 9 ช่อง: ATM, ประกันสังคม, กองทุนเลี้ยงชีพ, ค่าแรงค้างงวดก่อน (ป้ายเดิมสะกด "ค่าแรงค้างวิคก่อน"), ภาษี, โบนัส, ค่าพักร้อน, รวมค่าแรง, เงินได้สุทธิ
- ⚠ ช่อง "ค่าพักร้อน" พิมพ์ฟิลด์ `HOT` (เงิน 10 บาท × วันทำงาน — BR-003 ค) ไม่ใช่ค่าพักร้อนจาก BR-031 (✅ เลย์เอาต์รายงาน `พิมพ์SLIP`) ❓ Q-08
ลงนาม: ผู้รับเงิน (เส้นจุด) / แผนกบุคคล + ผู้จัดการโรงงาน (ชื่อพิมพ์เหนือเส้น — Label ในรายงาน ไม่ใช่รูป, #55)
ยืนยัน Q-02: ช่องประกันสังคม/กองทุน/ภาษี **ว่างจริง** · รวมค่าแรง = เงินได้สุทธิ
lot 3 (ช่วงที่ 2): แบบเดียวกันทุกช่อง — แถบหัวแสดงวันที่ของช่วงที่ 2 และวันจ่ายของงวด

### RPT-05 — เงินเดือนส่งแบ็งค์ทหารไทย / เงินOTส่งแบ็งค์กสิกร
หัว H3 Cordia · ท้ายหน้า วันที่พิมพ์ + **"Page x of y"**
- ทหารไทย: (ลำดับ) ชื่อ-นามสกุล, จำนวนเงิน, วันที่ (⚠ ว่าง), เลขบัญชี · เรียงเลขบัญชี ↑ · ท้าย "รวม n รายการ  จำนวนเงิน Σ"
- กสิกร: (ลำดับ) เลขบัญชี, คำนำหน้าอังกฤษ (`Mr.`), ชื่อ-นามสกุล**ภาษาอังกฤษตัวพิมพ์ใหญ่**, จำนวนเงิน · ท้าย "รวม n รายการ  จำนวนเงิน Σ" (Σ ไม่มีทศนิยม ต่างจากรายการ)
ทั้งสองถูก export เป็น Excel ส่งธนาคาร (INT-01, INT-02)
