# Reports — ระบบพนักงานและค่าแรง

ระบบเดิมมี 75 รายงาน ทุกรายงานเป็นแบบพิมพ์ (preview แล้วพิมพ์) ไม่มี export Excel/PDF ✅
**เลย์เอาต์ ป้ายข้อความ สูตรทุกช่อง การจัดกลุ่ม/เรียง และตำแหน่ง (ซม.) ของทุกรายงาน** อยู่ใน `legacy/reports/<ชื่อรายงาน>.md` ไฟล์นี้สรุปหน้าที่และกฎ ส่วนการคำนวณเบื้องหลังอยู่ใน business-rules.md (BR-060…BR-073)
รายงานหลักของรอบค่าแรงมีรายละเอียดด้านล่าง ส่วนที่เหลือมีแค่ข้อมูลระดับรายการ เพราะ:
- ❓ Q-39: ต้องให้ผู้ใช้เลือกก่อนว่ารายงานไหนยังใช้อยู่ แล้วค่อยถอดคอลัมน์และรูปแบบละเอียด
- รูปแบบหน้ากระดาษให้ดูจากระบบเดิม (ขอไฟล์ PDF ตัวอย่างจากผู้ใช้ — ❓ Q-40)

รูปแบบทั่วไป:
- หัวรายงานแสดงวันที่พิมพ์ `Now()`
- ท้ายรายงานมีเลขหน้า "Page x of y"
- ฟอนต์ไทย Angsana New / Cordia New / LilyUPC

## รายงานหลักของรอบค่าแรง

### RPT-01 — เวลาทำงานรายคน (ตัด WEEK)
ที่มา: รายงาน `คำนวณเวลาทำงาน13` ← คิวรี `คำนวณเวลาทำงาน13` · เปิดจาก SCR-40
พารามิเตอร์: FROM_DA, TO_DA
แถว: หนึ่งแถวต่อพนักงานที่ W+L+S+H+HOLI+SUN > 0
คอลัมน์: ลำดับ (running count), ID, NAME, W (วัน), L (วันลาได้ค่าแรง), O1, S, O2, H, O3 (ชั่วโมง)
หัวรายงาน:
- จำนวนวันในงวด `TO−FROM+1`
- วันทำงาน `TO−FROM+1−HOLI−SUN`
- จำนวนวันหยุดประเพณี/ประจำสัปดาห์
ท้ายรายงาน: จำนวนคน · เรียง: ID ↑ 🔍

### RPT-02 — ค่าแรงรายคน (ตามแผนก)
ที่มา: รายงาน `ค่าแรง1` ← `คำนวณค่าแรง73` · เปิดจาก SCR-41
พารามิเตอร์: แผนก (`*` = ทั้งหมด)
เงื่อนไข: แผนก LIKE พารามิเตอร์ และ PAY_W + PAY_OT > 0
คอลัมน์: ลำดับ, ID, NAME, SA (เงินเดือน/ค่าแรงต่อวัน), W, L, OT (ชม. O1), TT_OT (ชม. วันหยุด), PAY_W, PAY_OT, รวม = PAY_W + PAY_OT + HOT
ผลรวมท้ายรายงาน: จำนวนคน, Σ W, Σ L, Σ OT, Σ TT_OT, Σ PAY_W, Σ PAY_OT, Σ รวม · เรียง: ID ↑
หัวรายงาน: ชื่อแผนก, วันสิ้นงวด

### RPT-03 — สรุปค่าแรงรายแผนก
ที่มา: รายงาน `สรุปค่าแรง` ← `ค่าแรงส่งแบงค์1002` · มาโคร `สรุปค่าแรง` (เมนู 9)
แถว: หนึ่งแถวต่อแผนก: จำนวนคน, Σ PAY_W, Σ PAY_OT, รวม (+HOT), **%OT = PAY_OT / PAY_W × 100**
หัวรายงาน:
- งวด, วันจ่าย
- จำนวนวันในงวด, วันทำงาน (หักวันหยุดประจำสัปดาห์และวันหยุดประเพณี), วันทำงาน (หักเฉพาะวันหยุดประจำสัปดาห์)
- จำนวนรายการโอน, ค่าธรรมเนียม (จำนวน × 10)
ท้ายรายงาน: ผลรวมทุกคอลัมน์ และ %OT รวม

### RPT-04 — สลิปเงินเดือน
ที่มา: รายงาน `พิมพ์SLIP` ← ตาราง SLIP (BR-034) · มาโคร `SLIP` (และ `SLIPช่วงที่1/2`, `SLIPรวมโบนัส`)
หนึ่งหน้า/ส่วนต่อคน:
- รหัส, ชื่อ, งวด, วันจ่าย, ค่าแรงต่อวัน
- จำนวนวัน (งวด / อาทิตย์ / วันหยุด / วันทำงาน)
- W, L, ชั่วโมง S, H, O1, O2, O3
- เงิน: SALA, S_W, H_W, OT, OT2, OT3, HOT, ATM
- ช่องว่าง: SO_S, FA_L, INS, TAX
- TT, NET, ลายเซ็น
❓ Q-02 ช่องหักไม่เคยเติม — ถูกต้องหรือพิมพ์แล้วเขียนมือ

### RPT-05 — รายงานส่งธนาคาร
| รายงาน | ที่มา | คอลัมน์ | ผลรวม |
|---|---|---|---|
| `เงินเดือนส่งแบ็งค์ทหารไทย` | ตาราง เงินเดือนส่งแบ็งค์ | ลำดับ, เลขบัญชี ACC, ชื่อ, จำนวนเงิน | จำนวนราย, ยอดรวม |
| `เงินOTส่งแบ็งค์กสิกร` | ตาราง เงินOTส่งแบ็งค์ | ลำดับ, ACC2, TITLE, ชื่ออังกฤษ, จำนวนเงิน | จำนวนราย, ยอดรวม |
| `หนังสือนำส่งข้อมูล` | คิวรี หนังสือนำส่งข้อมูล | วันที่, จำนวนรายการ, ยอดรวม, วันจ่าย (+ ค่าธรรมเนียม 10 บาท/รายการ) | – |
| `ค่าแรงส่งแบงค์` / `เงินเดือนส่งแบ็งค์ทหารไทย1` | ตาราง ค่าแรงส่งแบงค์10 | ชื่อ, ACC, ยอด (PAY_W+PAY_OT+HOT), วันจ่าย | |
กฎยอดเงิน: BR-033 · เรียงตามเลขบัญชี ↑

### RPT-06 — คู่มือวิธีทำเงินเดือนส่งแบงค์
รายงาน `PAYROLL 1` (ทหารไทย), `PAYROLL 2` (กสิกรไทย) เป็นหน้าข้อความคู่มือขั้นตอน ไม่มีข้อมูล 🔍 ข้อความนี้บอกว่าผู้ใช้ทำอะไรต่อหลังพิมพ์ — ❓ Q-03 ขอเนื้อหามาประกอบ integrations.md

### RPT-08 — ค่าแรงสิ้นเดือน / สรุปบัญชีคำนวณค่าจ้าง
ที่มา: มาโคร `พิมพ์ค่าแรงสิ้นเดือน` → รายงาน `พิมพ์ค่าแรงสิ้นเดือน5` (รายคน) และ `สรุปบัญชีคำนวณค่าจ้าง` (รายแผนก)
พารามิเตอร์: ช่วงวันที่ F_D–T_D, แผนก
แหล่งข้อมูล: ประวัติ `สำเนาของ ค่าแรง` ในช่วงวันที่ (รวมหลายงวด)
คอลัมน์รายคน:
- ID, NAME, เลขบัตร
- อัตรา (รายเดือน = SALARY, รายวัน = SA_DAY)
- จำนวนวัน (รายวัน = Round(ΣPAY_W / SA_DAY, 1), รายเดือนเว้นว่าง)
- ค่าจ้าง (รายเดือน = SALARY, รายวัน = ΣPAY_W)
- รวม = ΣPAY_W + ΣPAY_OT
ท้ายรายงานแสดงข้อความ "ตรวจสอบพนักงานที่ลาออกให้เรียบร้อย"
🔍 รายงานนี้น่าจะใช้ส่งบัญชี/ทำต้นทุน (มีปุ่ม "พิมพ์สรุป (ต้นทุน)")

### RPT-09 / RPT-10 — สรุปค่าแรงแต่ละเดือน / รวมค่าแรง
ที่มา: มาโคร `สรุปค่าแรงแต่ละเดือน33333` (สร้างตารางรายเดือน 12 คอลัมน์จากประวัติ) / `รวมค่าแรง`
พารามิเตอร์: ช่วงเดือน 🔍 · ❓ Q-39 รายละเอียด
