# Screens — ระบบพนักงานและค่าแรง

ระบบเดิมเปิดที่ฟอร์ม `Switchboard` (เมนูปุ่มสูงสุด 8 ปุ่มต่อหน้า อ่านรายการจากตาราง `Switchboard Items`) ทุกหน้าจอเปิดจากเมนูนี้
ผู้ใช้ทุกคนเห็นทุกเมนู (ไม่มีสิทธิ์)

หน้าจอส่วนใหญ่มี 2 แบบ:
- **ฟอร์มกรอกพารามิเตอร์**: ช่วงวันที่/แผนก แล้วกดปุ่ม "คำนวณ"/"พิมพ์" ซึ่งรันมาโครและเปิดรายงาน
- **ฟอร์มกรอกข้อมูล**: แบบ datasheet หรือทีละรายการ

ระบบใหม่ไม่จำเป็นต้องเลียนแบบโครงเมนูเดิม แต่ต้องมีทุกฟังก์ชัน ❓ Q-36 ผู้ใช้อยากได้เมนูแบบเดิมหรือจัดใหม่

### SCR-30 — บันทึกการลา
ที่มา: ฟอร์ม `รหัส1` (เลือกพนักงาน) → มาโคร `ลางานรายคน1` (คำนวณสรุปวันลาที่ใช้ไป) → ฟอร์ม `LEAVE_A`

### SCR-41 — พิมพ์ค่าแรง (เลือกแผนก)
ช่อง: แผนก (`NAME_DE`, `*` = ทั้งหมด) → มาโคร `คำนวณค่าแรง` → BR-003..006 + ตารางส่งธนาคาร → รายงาน `ค่าแรง1` (กรองแผนก, เฉพาะยอด > 0)
⚠ ต้องทำ SCR-40 ก่อนเสมอ เพราะใช้ช่วงวันที่และ WORK_T จากขั้นนั้น ระบบใหม่ควรรวมเป็นขั้นตอนเดียวหรือบังคับลำดับ

### SCR-60 — ย้ายข้อมูล (การทำงาน/การลา/ใบเตือน)
ช่อง: วันที่ตัด (`DAT` หรือเลือกเดือน) → ปุ่มย้าย → หน้าจอเตือนยืนยัน → BR-040 → ข้อความเสร็จ

### SCR-62 — ลบข้อมูลปีที่แล้ว
ช่อง: ลบถึงวันที่ `TO_DATE` → หน้าจอเตือน → BR-042
