# คำศัพท์ — วัตถุดิบ (จัดซื้อ รับของ และสต็อกวัตถุดิบ)

> สถานะ: **ถอดครบ — รอยืนยัน** · อัปเดต 2026-10-05
> ที่มา: ป้ายบนฟอร์ม/รายงาน (`source/_extract/วัตถุดิบ/recovered/forms_digest.txt`, `reports_digest.txt`) + ชื่อฟิลด์/ตาราง
> ใช้คำในคอลัมน์ "คำ" คำเดียวตลอดทุกไฟล์ของโปรแกรมนี้

| คำ | ความหมาย | ชื่อในระบบ (ตาราง/ฟิลด์) | หมายเหตุ |
|---|---|---|---|
| วัตถุดิบ | ของทุกอย่างที่ซื้อผ่านโปรแกรมนี้ ทั้งวัตถุดิบผลิต อะไหล่ เครื่องมือ ค่าบริการ และสินค้าซื้อมาขาย หนึ่งรหัส = หนึ่งรายการ | T-MTR_NAME (`CODE`) | ระบบเดิมเรียก "วัตถุดิบ" รวมทุกอย่าง แม้เป็นค่าบริการ (เช่น `MI1411` อบรม) |
| วัตถุดิบหลัก | วัตถุดิบที่ใช้ผลิตผ้าเบรก/ดิสเบรก/ผ้าคลัทช์โดยตรง — เป็นตัวกำหนดว่าจะเข้าสต็อก, ต้องตรวจรับ QA และนับในรายงานวัตถุดิบหลัก | T-MTR_NAME.`INCOMING` = `ใช่` | นิยามจากป้ายฟอร์ม `MTR_NAME` (BR-003) |
| ผู้ขาย | บริษัท/ร้านที่ขายหรือให้บริการ | T-SP (`CODE`) | ป้ายบางที่ใช้ "ผู้จำหน่ายปัจจัยการผลิต", "เจ้าหนี้" — หมายถึงสิ่งเดียวกัน |
| ผู้ขายที่ใช้ในการผลิต | ผู้ขายที่ต้องถูกประเมินและอยู่ในทะเบียนผู้ขาย (Approved Supplier List) | T-SP.`USE IN PRODUCT` = `ใช่` | |
| แผนก | แผนกที่ขอซื้อ มีรหัส prefix ของเลขที่ใบขอซื้อ และชื่อหัวหน้า | T-รายชื่อแผนก | 12 แผนก (data-model "ข้อมูลอ้างอิง") |
| ใบขอซื้อ (PR) | ใบขออนุมัติสั่งซื้อ — แผนกขอให้จัดซื้อซื้อของ หนึ่งใบมีได้หลายรายการ | เลขที่ `PR_NO`, ลำดับ `PR_SUF`; รายการค้างอยู่ใน T-PO_RECEI | ป้ายเดิม: "ใบขออนุมัติสั่งซื้อ", "ใบขอซื้อ", "P/R" |
| เลขที่ใบขอซื้อ | รูปแบบ `<prefix แผนก><ปี พ.ศ. 2 หลัก>-<ลำดับ 4 หลัก>` เช่น `B69-0086`, `DM69-0015` | `PR_NO`, ทะเบียน T-PO_RECEI_ADD | BR-010 |
| ใบสั่งซื้อ (PO) | ใบสั่งซื้อถึงผู้ขายหนึ่งราย หนึ่งใบมีได้ 1–10 รายการ แต่ละรายการมาจากรายการใบขอซื้อ | เลขที่ `PO_NO`, ลำดับ `PO_SUF`; รายการค้างรับอยู่ใน T-PO_RECEI4 | ป้าย: "ใบสั่งซื้อ (Purchase Order)" |
| เลขที่ใบสั่งซื้อ | ตัวเลข 6 หลัก `<ปี พ.ศ. 2 หลัก><ลำดับ 4 หลัก>` เช่น `690988` | `PO_NO`, ทะเบียน T-PO_NO | ผู้ใช้พิมพ์เอง (BR-020) |
| ยอดค้างสั่ง | จำนวนในรายการใบขอซื้อที่ยังไม่ได้ออกใบสั่งซื้อ = จำนวนขอซื้อ − จำนวนสั่งซื้อ | `DIF_QTY` | BR-021 |
| รับของ / รับวัตถุดิบ | บันทึกว่าผู้ขายส่งของตามใบสั่งซื้อมาแล้ว (วันที่, จำนวนรับจริง) | `RE_DATE`, `RE_QTY`; ประวัติอยู่ใน T-PO_RECEI5 | |
| ยอดค้างส่ง | จำนวนสั่งซื้อที่ผู้ขายยังส่งไม่ครบ = จำนวนสั่งซื้อ − จำนวนรับ | `DIF_QTY1` | BR-030 |
| รับไม่ครบ | รายการที่รับแล้วแต่ยังมียอดค้างส่ง | `PUR_ID` = `N` | ชื่อฟิลด์ไม่สื่อ — ดู data-model |
| ผลการส่ง | ผู้ขายส่งทันวันที่ต้องการหรือไม่ | `SEND` = `ทัน` / `ไม่ทัน` | BR-030 |
| ผลการตรวจสอบ (QA) | ผลตรวจรับวัตถุดิบ | `PASS` = `ผ่าน` / `ไม่ผ่าน` | |
| ใบรับรอง | ผู้ขายแนบใบ Certificate มากับสินค้าหรือไม่ | `NOPASS` = `มี` / `ไม่มี` | ชื่อฟิลด์ `NOPASS` ไม่สื่อ — ความหมายจากป้าย "ใบรับรอง" |
| LOT | หมายเลข Lot ของวัตถุดิบที่รับ (QA บันทึก) | `LOT` | |
| ใบเบิก | เอกสารเบิกวัตถุดิบออกจากสต็อก หนึ่งใบหลายรายการ | T-Stock แถว `MARK` = `tr`, เลขที่ใน `INVOICE_NO` เช่น `002/0098` | ป้ายฟอร์ม "บันทึกการเบิกวัตถุดิบ" |
| ความเคลื่อนไหวสต็อก | หนึ่งแถว = รับเข้า (บวก) หรือเบิกออก (ลบ) หรือยอดยกมา | T-Stock | BR-040, BR-041 |
| ยอดยกมา | ยอดคงเหลือรายวัตถุดิบ ณ วันตัดสต็อก ที่ระบบสร้างเป็นแถวเดียวต่อรหัส | T-Stock แถว `INVOICE_NO` = `stock`; สำเนาใน T-ต้นงวดP_ST | BR-042 |
| ตัดสต็อก | งานสิ้นเดือน: สรุปความเคลื่อนไหวถึงวันที่กำหนดเป็นยอดยกมา แล้วลบแถวเก่าออกจาก T-Stock | macro `ตัดSTOCK` | BR-042 |
| STOCK CARD | รายงานความเคลื่อนไหวและยอดคงเหลือของวัตถุดิบหนึ่งรหัส | RPT-14 | |
| ประเมินผู้ขาย (รายไตรมาส) | ให้คะแนนผู้ขายจากผลตรวจ ใบรับรอง การส่งทัน และคะแนนบริการ 2 ข้อ แล้วตัดเกรด A–D | T-ประเมินผู้ขาย | BR-050 |
| ไตรมาส | ช่วงประเมิน ผู้ใช้พิมพ์เลข 1–4 | `TERM` | |

| ผู้จัดซื้อ | หน่วยที่ออกใบสั่งซื้อ: `F` โรงงาน, `O` ออฟฟิศ สีลม | `PUR` (lookup T-PURC) | ป้ายฟอร์มใช้ทั้ง "ผู้จัดซื้อ" และ "ผู้สั่งซื้อ" |
