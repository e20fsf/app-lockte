## วัตถุประสงค์
🔍 อนุมานจากเมนู ป้ายฟอร์ม และข้อมูล (❓ Q-01): ระบบงานจัดซื้อของโรงงานผลิตผ้าเบรก/ผ้าคลัทช์/ดิสเบรก (บริษัท ล็อคเต้ จำกัด) ตั้งแต่แผนกขอซื้อจนรับของเข้าคลัง
1. **ขอซื้อ** — แผนกออกใบขออนุมัติสั่งซื้อ (PR) เลขที่แยกตามแผนกและปี
2. **สั่งซื้อ** — จัดซื้อออกใบสั่งซื้อ (PO) จากรายการขอซื้อ คิด VAT 7% พิมพ์ส่งผู้ขาย ติดตามของค้างรับ
3. **รับของ + ตรวจรับ** — บันทึกรับ (ครบ/บางส่วน/ไม่ผ่าน) ผลการส่งทัน/ไม่ทัน; QA บันทึก LOT ผลตรวจ ใบรับรอง
4. **สต็อกวัตถุดิบหลัก** — รับเข้าอัตโนมัติ เบิกด้วยใบเบิก STOCK CARD ตัดสต็อกสิ้นเดือนพร้อมมูลค่า
5. **ผู้ขาย** — ทะเบียน, ทะเบียนผู้ขายที่อนุมัติ (ASL), ประเมินรายไตรมาส/รายปีตามระบบคุณภาพ ISO

## ขอบเขต
**ทำ:** (ตามเมนูที่ใช้งานอยู่ — screens.md แผนผังเมนู)
- ข้อมูลหลัก: ผู้ขาย, วัตถุดิบ, แผนก, ทะเบียนเลขที่เอกสาร
- ใบขอซื้อ: ออกเลข, กรอก, พิมพ์, แก้ไข/ลบ/พิมพ์ซ้ำ
- ใบสั่งซื้อ: ออกจากรายการขอซื้อ (เต็ม/บางส่วน), คำนวณ VAT, พิมพ์ (จำนวนเงินตัวอักษร), แก้ไข/ลบ/พิมพ์ซ้ำ
- รับของ: รับครบ/บางส่วน/ตรวจไม่ผ่าน, แก้ไข/ลบการรับ, QA ตรวจรับ, อัปเดตราคา/ผู้ขายล่าสุด
- สต็อก: รับเข้าอัตโนมัติ (วัตถุดิบหลัก), เบิก, STOCK CARD, ปรับยอด, ตัดสต็อก + มูลค่า
- รายงาน: ค้างสั่ง/ค้างรับ, ยอดซื้อตามแผนก/วัตถุดิบ/ผู้ขาย/เดือน/ปี, วัตถุดิบหลัก, ซื้อมาขาย, ใบสั่งซื้อต่ำกว่า 5,000, อลูมิเนียมหลอม
- ผู้ขาย: ทะเบียน ASL, หนังสือมุ่งมั่น มรท., ประเมินรายไตรมาส (คะแนน/เกรด), แบบประเมินรายปี
- งานประจำปี (ก.พ.): ลบข้อมูลปีที่แล้ว (❓ Q-05)

**ไม่ทำ (Out of scope):**
- บัญชีเจ้าหนี้, ใบแจ้งหนี้ของผู้ขาย, การจ่ายเงิน, ภาษีซื้อ — ระบบเดิมไม่มี (INT-03)
- ส่วนลด, สกุลเงินต่างประเทศ (ระบบเดิมไม่มี)
- การตัดสต็อกวัตถุดิบตามผลผลิต/สูตรการผลิต — เบิกด้วยมือเท่านั้น (ผลผลิตอยู่โปรแกรม `ผลผลิตและORDER.accdb`)
- ข้อมูลพนักงาน (โปรแกรม `พนักงาน.accdb`)
- login/สิทธิ์/workflow อนุมัติในระบบ — ระบบเดิมไม่มี (❓ Q-41 หมวด ข.)
- ของที่ไม่มีทางเข้าจากเมนู จนกว่าผู้ใช้ยืนยัน (❓ Q-02)
