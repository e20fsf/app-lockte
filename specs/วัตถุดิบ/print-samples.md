## เอกสารจัดซื้อ (RPT-01, 02, 11)

### RPT-01 — ใบขออนุมัติสั่งซื้อ
หัว: "บริษัท ล็อคเต้ จำกัด (LOCKTE CO.,LTD.)" + ที่อยู่สำนักงานสีลมและโทรศัพท์โรงงาน 2 บรรทัด (ไทย / อังกฤษ) ตัวเล็ก → "ใบขออนุมัติสั่งซื้อ" + เลขเอกสารขวา
บรรทัดหัว: เลขที่ใบสั่งซื้อ (ซ้าย), ☐ เอกสารเลขที่ (ขวา), วันที่สั่งซื้อ, แผนกที่ขอซื้อ
ตารางเส้นเต็ม **12 แถวคงที่**: ลำดับ, รหัส, รายการ, จำนวน, หน่วย, ราคาต่อหน่วย, จำนวนเงิน → "รวมรายการ n รายการ" → กล่อง เหตุผลในการซื้อ → กล่อง หมายเหตุ
ท้าย: กล่อง 3 ช่อง — "วันที่ต้องการของ ____" + ผู้สั่งซื้อ / ผู้อนุมัติ (ผู้จัดการฝ่าย) / ผู้อนุมัติ (ผู้จัดการโรงงาน) — reports.md นับเป็น 4 ลายเซ็น แต่ "ผู้อนุมัติ" คือป้ายของสองช่องหลัง
ตัวอย่างเป็นใบเปล่า (ไม่มีรายการที่เลือก — "รวมรายการ 0 รายการ")

### RPT-02 — ใบสั่งซื้อ (Purchase Order)
หัวบริษัทเหมือน RPT-01 → "ใบสั่งซื้อ" / "(Purchase Order)" + เลขเอกสารขวา + ☐ เลขที่
กล่องหัว 2 ฝั่ง: ซ้าย ถึง(To), ที่อยู่(Address), โทรฯ, FAX · ขวา แผนกที่ขอซื้อ (Department), วันที่ส่งสินค้า (Delivery Date), กำหนดการชำระเงิน (Term) ___ วัน
ตารางเส้นเต็ม **11 แถวคงที่** หัวสองภาษา: ลำดับ (No.), เลขที่ใบขอซื้อ (P/R No.), รายละเอียด (Description), จำนวน (Quantity), หน่วย (Unit), ราคาต่อหน่วย (Unit Price), จำนวนเงิน (Amount) → "รวมรายการ (Total Descriptions) n รายการ"
ใต้ตาราง: เหตุผลในการสั่งซื้อ / หมายเหตุ (Remark) / รวมจำนวนเงิน(ตัวอักษร)(Total Amount in words) ซ้าย · รวมราคาทั้งสิ้น (Sub Total) / ภาษีมูลค่าเพิ่ม 7% (Value Added Tax 7%) / จำนวนเงินทั้งสิ้น (Grand Total) ขวา
ข้อความท้ายตัวหนา (✅ ข้อความเต็มที่ reports.md กู้ไม่ได้): **"โปรดระบุเลขที่ใบสั่งซื้อลงในใบส่งของ/ใบกำกับภาษีทุกครั้ง"** / "(Please sign Purchase Order Number in Invoice/Tax Invoice.)"
กล่องลงนาม 3 ช่อง: ผู้จัดทำใบสั่งซื้อ (Prepared by) / ผู้ตรวจสอบใบสั่งซื้อ (Reviewed by) / ผู้อนุมัติสั่งซื้อ (Apporved by) + วันที่ (Date) ใต้ทุกช่อง
⚠ ใบเปล่าพิมพ์ **`#Error`** ในช่องจำนวนเงินตัวอักษร (D-3) · สะกด "Apporved" · สำนวนอังกฤษ "Please sign … Number" ไม่ตรงความหมาย (ควรเป็น "quote") · ป้าย "วัน" ของ Term พิมพ์แม้ว่าง

### RPT-07 — แบบผลการประเมินติดตามผู้ขายประจำไตรมาส
หัว H1 + เลขเอกสารขวาบน · "วันที่ประเมิน … ไตรมาสที่ … ตั้งแต่วันที่ … ถึงวันที่ …" (ขีดเส้นใต้)
1. รายละเอียดผู้จำหน่ายปัจจัยการผลิต — ตาราง 2 คอลัมน์ 7 แถว: รหัส, ชื่อ, ที่อยู่, เบอร์โทรติดต่อ, ประเภทผลิตภัณฑ์, ประเภทธุรกิจ, ใบรับรองคุณภาพ
2. หัวเรื่องการประเมิน — ตาราง: ระบบคุณภาพ | รายละเอียดการประเมิน (มีแหล่งข้อมูลในวงเล็บ เช่น "(ดูจากใบ NCR)") | ผลการประเมิน ("มีใบ (NCR) n ใบ คะแนนเต็ม 5 ได้ n คะแนน")
   - การควบคุมคุณภาพ: 1. รายละเอียดสินค้าตรงตามความต้องการ, 2. การรับรองคุณภาพ ("ไม่มีใบรับรองมา n ครั้ง")
   - การจัดส่ง: ความรวดเร็ว ("ล้าช้า n ครั้ง")
   - การบริการ: 1. การรับฟัง-ตอบปัญหา, 2. การตอบสนองข้อร้องเรียน (คะแนน + ข้อความ เช่น "ดีมาก")
→ คะแนนที่ได้รับรวม (เต็ม 25), คิดเป็นเปอร์เซ็นต์ (ทศนิยม 2), ผลการประเมิน + เกรด
ท้าย: กล่อง Comments พร้อมเกณฑ์เกรดพิมพ์คงที่ (A ≥ 80% ผู้ขายชั้นดี · B 70–79 · C 60–69 · D 55–59 ห้ามสั่งซื้อนอกจากได้รับคำสั่ง) + Prepared by / Reviewed by / Approved by
⚠ "ไม่มีใบรับรองมา" นับทุกครั้งที่รับของ (ตัวอย่างหลายร้อยครั้ง) · สะกด "ล้าช้า" · เกณฑ์ไม่มีระดับต่ำกว่า 55% 🔍 (เทียบ BR-050)

### RPT-08 — แบบประเมินผู้ขายประจำปี
หัว H1 ตัวเล็ก + ชื่อแบบ + เลขเอกสารขวา · "วันที่ทำการประเมิน <วันพิมพ์ ยาว> ประจำปี <ปี> ครั้งที่ 1" · ☐ การประเมินประจำปีปกติ ☐ การประเมินซ้ำ
1. รายละเอียดผู้จำหน่าย (5 แถว) → 2. หัวข้อการประเมิน 21 ข้อในตารางเส้นเต็ม แบ่ง ระบบคุณภาพ (1–11 → A), ระบบควบคุม (12–15 → B), อื่นๆ (16–21 → C), D = A+B+C — ช่องคะแนนพิมพ์ตัวเลือก `5 - - - - 0` หรือ `5 4 3 2 1 0` ให้วงด้วยมือ (ข้อ 1: มี 50 / ไม่มี 0)
3. ข้อบกพร่องในการจัดส่ง (3.1 ส่งสินค้าเสีย, 3.2 ความล่าช้า: รุนแรง 5 / ปานกลาง 3 / น้อย 1) → E
ท้าย: รวมคะแนน = (D) − (E), ☐ ผ่าน ☐ ไม่ผ่าน, เกณฑ์ "ผ่าน ≥ 80 / ไม่ผ่าน ≤ 79", ข้อเสนอแนะ, PREPARED BY / REVIEWED BY / APPROVED BY
