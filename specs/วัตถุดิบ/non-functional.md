# ข้อกำหนดที่ไม่ใช่ฟังก์ชัน — วัตถุดิบ

> สถานะ: **ถอดครบ — รอยืนยัน** · อัปเดต 2026-10-05
> ที่มา: โครงสร้างไฟล์, ข้อมูลจริง (นับแถว/ช่วงวันที่), ป้ายบนฟอร์ม, การตั้งเครื่องพิมพ์ที่บันทึกในฟอร์ม/รายงาน

## สิทธิ์ผู้ใช้
ระบบเดิม**ไม่มี login และไม่มีการแบ่งสิทธิ์** — ไม่พบ `CurrentUser`, `Environ`, ตารางผู้ใช้ หรือรหัสผ่าน ทุกคนที่เปิดไฟล์ทำได้ทุกอย่างรวมถึงตัดสต็อกและลบข้อมูลปี การควบคุมมีเพียงป้ายเตือนบนฟอร์ม:
- ตัดสต็อก: "ห้ามผู้ที่ไม่มีหน้าที่มาทำการตัด STOCK เองโดยเด็ดขาด … (อย่าคลิกคำสั่งพิมพ์)" + ป้าย "ผู้จัดการโรงงาน"
- ลบข้อมูลปีที่แล้ว: กล่องถามยืนยัน "ใช่/ไม่" เท่านั้น
- ไฟล์เปิดแบบเห็นหน้าต่างฐานข้อมูล (`StartupShowDBWindow` = True) → ผู้ใช้แก้ตาราง/query ได้โดยตรง

## รูปแบบข้อมูล
| เรื่อง | พฤติกรรมเดิม |

| วันที่ (แสดง) | `Short Date`/`Long Date` ตาม regional setting ของ Windows — เครื่องที่ใช้ตั้งเป็น **พ.ศ.** 🔍 (ปี 2 หลักในเลขเอกสาร = พ.ศ.) |

| VAT | 7% hard-code |
| ข้อความไทย | เก็บ Unicode (Access) · การเรียงตามชื่อ (รายงาน/dropdown) ใช้ collation ของ Access ภาษาไทย 🔍 |

## Audit / Backup
- ไม่มีการเก็บประวัติว่าใครแก้/ลบอะไร เมื่อไร (ไม่มีฟิลด์ผู้บันทึก/เวลาบันทึก)
- การลบทุกแบบเป็น hard delete (BR-013, 025, 033, 034, 070) และไม่มีการยืนยันยกเว้นลบข้อมูลปี
- ไม่มี backup ในโปรแกรม ❓ Q-26
- เอกสารระบบคุณภาพ (ISO) อ้างรหัสฟอร์มบนรายงาน เช่น `PC-PU002-2/2547`, `II-QA001/2548` — ผลประเมินผู้ขายเก็บถาวรใน T-ประเมินผู้ขาย (ตั้งแต่ 2005)
