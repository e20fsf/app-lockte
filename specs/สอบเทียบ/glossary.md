# คำศัพท์ — สอบเทียบ

> สถานะ: ร่าง — รอยืนยัน (2026-10-05)

| คำ | ความหมาย | ชื่อในระบบ (ตาราง/ฟิลด์) | หมายเหตุ |
|---|---|---|---|
| เครื่องมือวัด | อุปกรณ์วัดที่ต้องควบคุมและสอบเทียบตามระบบคุณภาพ หนึ่งแถว = หนึ่งเครื่อง | T-CALIPER, T-PRESSURE GAUGE, T-เครื่องชั่ง, T-ตัวควบคุมอุณหภูมิ, T-jig, T-ภายนอก | ระบบเดิมแยกตารางตามชนิด |
| ชนิดเครื่องมือวัด | กลุ่มของทะเบียน 6 กลุ่ม: ภายนอก, เวอร์เนีย (CALIPER), เพรสเชอร์เกจ, เครื่องชั่ง, JIG, ตัวควบคุมอุณหภูมิ | ชื่อตาราง | ในระบบเดิมไม่มีฟิลด์ชนิด — ชนิด = ตารางที่เก็บ |
| หมายเลขเครื่อง | รหัสประจำเครื่องมือวัด เช่น `VN-QA012/2560` | `หมายเลขเครื่อง` (ทุกตาราง) | รูปแบบตาม BR-020; ในสติกเกอร์เรียก "ID" |
| สอบเทียบภายใน | สอบเทียบโดยพนักงานบริษัทเอง โดยใช้เครื่องมือมาตรฐานที่ผ่านการสอบเทียบภายนอกแล้ว | 5 ตาราง: CALIPER, PRESSURE GAUGE, เครื่องชั่ง, ตัวควบคุมอุณหภูมิ, jig | เมนู "สอบเทียบภานใน" (สะกดตามต้นฉบับ) |
| สอบเทียบภายนอก | ส่งเครื่องมือให้บริษัทภายนอก (บริษัทที่สอบเทียบ) สอบเทียบ | T-ภายนอก | ส่วนใหญ่เป็นเครื่องมือมาตรฐาน (gauge block, ตุ้มน้ำหนัก) — BR-021 |
| เครื่องมือมาตรฐาน | เครื่องมือที่ใช้สอบเทียบเครื่องมืออื่น ต้องผ่านการสอบเทียบแล้ว | `หมายเลขเครื่องมือที่ใช้(ผ่านการสอบเทียบแล้ว)`, `หมายเลขเวอร์เนียที่ใช้(ผ่านการสอบเทียบแล้ว)` | เป็นข้อความอิสระ — BR-021 |
| บริษัทที่สอบเทียบ | หน่วยงานภายนอกที่รับสอบเทียบ | T-บริษัทที่สอบเทียบ.NAME, T-ภายนอก.ผู้สอบเทียบ | รายงานเรียก "หน่วยงานสอบเทียบ" |
| ผู้สอบเทียบ | ภายใน: ชื่อพนักงานที่สอบเทียบ · ภายนอก: ชื่อบริษัทที่สอบเทียบ | `ผู้สอบเทียบ` | ความหมายต่างกันตามตาราง; รายงานบัญชีรายชื่อตั้งชื่อ control ว่า "กำหนดการสอบเทียบ" แต่แสดงฟิลด์นี้ (RPT-02) |
| วันที่ขึ้นบัญชี | วันที่ลงทะเบียนเครื่องมือวัดเข้าระบบ | `วันที่ขึ้นบัญชี` | ข้อมูลปน พ.ศ./ค.ศ. (data-model) |
| พิกัดใช้งาน | ช่วงการวัดที่ใช้งาน เช่น `0-150`, `190-210` | `พิกัดใช้งาน` | ข้อความ |
| ค่าความละเอียด | ความละเอียดของเครื่อง (resolution) เช่น `0.02` | `ค่าความละเอียด` | ข้อความ |
| ขีดจำกัดที่ยอมรับได้ | ค่าคลาดเคลื่อนสูงสุดที่ยอมรับ (acceptance limit) | `ขีดจำกัดที่ยอมรับได้` | ฟอร์มตั้งชื่อ control ว่า "ค่าความผิดพลาด" |
| แผนก | แผนก/เครื่องจักรที่ใช้งาน เช่น `QA`, `DC (D02)` = แผนก DC เครื่อง D02 | `แผนก`, `แผนกที่ใช้งาน` (T-ภายนอก) | 🔍 รหัสในวงเล็บ = เครื่องจักร ❓ Q-05 |
| JIG | อุปกรณ์จับ/วัดชิ้นงานก้ามเบรกเฉพาะรุ่นรถ (เช่น RX100, CLICK) | T-jig | "JIG วัดศูนย์" (วัดศูนย์ก้ามเบรก) และ "JIG กรอ" (กรอก้ามเบรก) — RPT-05/06 |
| แกน (mm) | ขนาดแกนของ JIG เช่น `7, 6` | T-jig.`แกน (mm)` | ❓ Q-06 |
| สติกเกอร์ | ป้ายติดเครื่องมือวัด แสดง ID / CAL / DUE | RPT-04 | |
| CAL | วันที่สอบเทียบ | ตาราง `วันที่ CAL`.CAL | |
| DUE | วันที่ต้องสอบเทียบครั้งต่อไป ("1 ปีนับจากวันที่สอบเทียบ" ตามป้ายฟอร์ม) | ตาราง `วันที่ CAL`.DUE | กรอกเอง ไม่คำนวณ (BR-010) |
| แบบฟอร์มบันทึกผลการสอบเทียบ | กระดาษพิมพ์จากระบบให้กรอกค่าที่วัดได้ 3 ครั้ง ค่าเฉลี่ย ค่าผิดพลาด ผ่าน/ไม่ผ่าน | RPT-03, RPT-05, RPT-06 | ผลไม่ย้อนกลับเข้าระบบ (BR-031) |
