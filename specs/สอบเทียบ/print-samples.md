## RPT-01 — แผนการสอบเทียบ
หัว H1 "บริษัท ล็อคเต้ จำกัด" / "แผนการสอบเทียบ" + เลขเอกสารขวา · ตารางเส้นเต็ม: ที่, กิจกรรม, ระยะเวลา, ผู้รับผิดชอบ, ผู้ตรวจสอบ, มค.…ธค.
**ช่องเดือนระบายสีเขียวไว้ในแบบรายงาน**: สอบเทียบภายนอก = กค., สอบเทียบภายใน = สค. (reports.md เข้าใจว่าเว้นว่างให้ขีดมือ — ที่จริงเดือนคงที่ในรายงาน)
ล่างซ้าย: หมายเหตุเครื่องทดสอบแรงเสียดทาน 3 ข้อ (500 rpm / temp control 100,150,200,250,300,350 °C / แรงกด 125 Kgs.) · ล่างขวา: กล่องลงนาม 3 ช่อง **จัดเตรียมโดย** / ตรวจสอบโดย / อนุมัติโดย

## RPT-02 — บัญชีรายชื่อเครื่องมือวัด
หัว H1 + "บัญชีรายชื่อเครื่องมือวัด(สอบเทียบภายนอก)" / "… (สอบเทียบภายใน)" + เลขเอกสารขวา · ตารางเส้นเต็ม 12 คอลัมน์ตาม reports.md (หัว "ขีดจำกัดที่ยอมรับได้" มี "±" ตัวเล็กใต้)
- วันที่ขึ้นบัญชีแสดง `d/m/yyyy` พ.ศ. (✅ 🔍 ใน reports.md) — ค่าที่เก็บปน ค.ศ./พ.ศ. (data-model) จึงพิมพ์ปีเป็น **2505, 2511, 3109, 3111** ตามจริง
- **กล่องลงนาม (จัดทำโดย / ตรวจสอบโดย / อนุมัติโดย) พิมพ์หน้าสุดท้ายเท่านั้น** ต่อจากแถวสุดท้าย (เดิมเข้าใจว่า "ท้ายทุกหน้า" — reports.md แก้ตามตัวอย่างพิมพ์แล้ว)
- `ภายนอก`: หมายเหตุเครื่องทดสอบแรงเสียดทานท้ายรายงาน ระบุ temp control **100,150,200,250** °C — ไม่ตรงกับ RPT-01 (ถึง 350) · ป้ายลงนามช่องแรก "จัดทำโดย" (RPT-01 ใช้ "จัดเตรียมโดย")
- `JIG`: ชื่อเครื่องมือ = ชื่อรุ่น JIG ตัวเล็กกว่าคอลัมน์อื่น · คอลัมน์ยี่ห้อ/พิกัด/ความละเอียด/หน่วยว่างทั้งหมด (✅ ⚠ ใน reports.md)
⚠ ผู้สอบเทียบภายนอกยาวถูกตัด (`Quality Calibratio`, D-1) · หน่วยเขียนไม่สม่ำเสมอ (`G`, `MM`, `KGS`, `Kg/cm²`, `°C`, `RPM.`)

## RPT-03 — บันทึกผลการสอบเทียบ
A4 ตั้ง · หัวกลาง "บริษัท ล็อคเต้ จำกัด" / "บันทึกผลการสอบเทียบ" + เลขเอกสารบรรทัดเดียวกัน + เส้นหนาใต้หัว · ฟอนต์ไม่มีหัว (sans) ทั้งใบ · ข้อมูลพิมพ์ทับเส้นจุด
- **ช่องติ๊กภายใน/ภายนอกพิมพ์เครื่องหมายไว้แล้ว** (วงกลมขีดทับ): `ภานนอก` ติ๊ก "สอบเทียบภายนอก", แบบอื่นติ๊ก "สอบเทียบภายใน"
- การวางฟิลด์ต่างจาก reports.md:
  - caliper / เครื่องชั่ง: ชื่อผู้สอบเทียบอยู่ในช่อง **"ผู้สอบเทียบ"** และช่อง "หน่วยงานสอบเทียบ" ว่าง
  - ภายนอก: บริษัทสอบเทียบอยู่ในช่อง **"หน่วยงานสอบเทียบ"** และ "ผู้สอบเทียบ" ว่าง
  - เครื่องชั่ง: แผนกพิมพ์ต่อท้ายชื่อเครื่องมือโดยไม่มีป้าย (เช่น `BL(32,33)`)
  - "หมายเลขเครื่องมือที่ใช้(ผ่านการสอบเทียบแล้ว)" พิมพ์เป็นช่วงหมายเลข (`GB-QA001/2551-GB-QA005/2551`)
- พิกัดใช้งาน / ขีดจำกัด พิมพ์พร้อมหน่วย (`0-300 mm`, `± 0.1 mm`) · pressure gauge: `50 - 150 Kg/cm²`, `±10 kg/cm²` · temp control: `190 - 210 °C`, `±10 °C` (✅ Q-13 — คงที่ตามรายงาน)
- ตารางผล 20 แถว: จุดที่, ค่ามาตรฐาน, ค่าที่วัดได้ 1/2/3, ค่าเฉลี่ย, ค่าผิดพลาด, หมายเหตุ → สรุปผล ○ ผ่าน ○ ไม่ผ่าน ซ้าย · ลงชื่อ (ผู้ประเมินผลการสอบเทียบ) + วันที่ ขวา
