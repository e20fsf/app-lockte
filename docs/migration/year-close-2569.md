# ปิดปี 2569 ใน Access: ลบ pd ซ้ำ + ตัดสต็อก/ตัดยอดแม่พิมพ์ครั้งเดียว (ตั๋ว #135)

> ไม่มีข้อมูลจริงในเอกสารนี้ (ตัวเลขเป็นยอดรวมจากการซ้อม) · ทำที่เครื่องของผู้ใช้ที่เปิดไฟล์ `ผลผลิตและORDER.accdb` ได้ (ฟอร์ม/มาโครทำงาน) ช่วง 2–5 ม.ค. 2570 · ชุดคำสั่ง: `tools/access-year-close/` · ผลจากรอบย้ายข้อมูลดู [full-run.md](full-run.md)

## ทำไมต้องทำ

- **ลบ pd ซ้ำ (Q-47, BR-005 ⚠):** รายการ `pd` ลงวันที่ 1–30 ธ.ค. 2568 อยู่ทั้งใน `P_ST` และ `P_ADDST` (โอนผลผลิตซ้ำช่วงที่ครอบวันตัดสต็อก) ยอดคงเหลือนับซ้ำ — ต้องลบก่อนย้ายข้อมูลรอบสุดท้าย
- **ตัดสต็อก/ตัดยอดแม่พิมพ์ครั้งเดียว ณ 31 ธ.ค. 2569:** ปี 2569 ยังไม่เคยตัดเลย (ตัดล่าสุด 31 ธ.ค. 2568) ระบบใหม่ต้องการยอดยกมาต่อสินค้าและยอดสะสมต่อแม่พิมพ์ที่ Access ตัดไว้แล้วเพื่อเทียบ (AC-11, AC-13)

## ขั้นตอนปิดปี (ทีละข้อ)

เก็บเลขที่ต้องตรวจของแต่ละขั้นลงตารางท้ายเอกสาร แล้วให้ผู้รับผิดชอบเซ็น

1. **สำรองไฟล์** — ปิดโปรแกรมทุกเครื่อง คัดลอก `ผลผลิตและORDER.accdb` เป็น `ผลผลิตและORDER_ก่อนปิดปี2569.accdb` (เก็บไว้ ห้ามแก้) · ตรวจ: ขนาดไฟล์สำเนาเท่าต้นฉบับ
2. **สโตร์โอนผลผลิตถึง 31 ธ.ค. 2569** (SCR-16 เมนู STOCK → "โอนผลผลิตเข้าSTOCK") ⚠ BR-005: **อย่าโอนช่วงที่ทับวันตัดสต็อกที่ตัดไปแล้ว** (ช่วงวันที่ต้องเริ่มหลัง 31 ธ.ค. 2568 — เช่น ใช้ 1 ม.ค. 2569 ถึง 31 ธ.ค. 2569) · ตรวจ: จำนวนใบผลผลิตของเดือนล่าสุดตรงกับสมุดที่แผนกส่ง
3. **ลบ pd ซ้ำ** (ที่เครื่องที่เปิดไฟล์ได้ ใช้ query ใน `tools/access-year-close/sql`): สร้าง query ใหม่ (Create → Query Design → ปิดหน้าต่างเพิ่มตาราง → มุมมอง SQL) วางทีละไฟล์ตามลำดับ แล้ว Run
   - `00` ล้างตารางทำงานของรอบก่อน (ข้อความ "ไม่พบตาราง" กด OK ข้ามได้)
   - `01` เก็บยอดคงเหลือต่อสินค้า **ก่อนลบ**
   - `02` หาแถวซ้ำเป๊ะ (วันที่ + REF_NO + SUF_NO + PD_C + QTY + MARK ตรงกับ P_ADDST ทุกช่อง) → ตาราง `bak_P_ST_dup_2569` · `03` หาแถวขอบเขตไม่ชัด (คีย์ 4 ช่องแรกตรง แต่ **จำนวนต่าง**) → `chk_P_ST_ambiguous_2569` (**รัน 02 และ 03 ก่อนลบอะไรทั้งสิ้น**)
   - `04` **ตรวจ: จำนวนแถว/Σ หน่วยที่จะลบ** (ซ้อมได้ 1,461 แถว / 1,122,413 หน่วย — ปีนี้ต้องใกล้เคียง; ถ้าต่างมากให้หยุดและถามทีมพัฒนา)
   - `04b` **ตรวจแถวขอบเขตไม่ชัด: จำนวนแถว/Σ หน่วย** (ซ้อม 1 แถว / 2,024 หน่วย; **ถ้ามากกว่า 10 แถวให้หยุดและถามทีมพัฒนา**) · `04c` **ดูแถวเหล่านั้นทีละแถว** — วันที่ เลขที่ บรรทัด สินค้า พร้อม "จำนวนใน P_ST (จะลบ)" เทียบ "จำนวนใน P_ADDST (ปิดงวดแล้ว เก็บไว้)" จดลงใบเซ็น
   - ผู้ใช้ตัดสินแล้ว (28 ต.ค. 2569) ว่าแถวขอบเขตไม่ชัดลบได้ — เพราะยอดที่ปิดงวดแล้วอยู่ใน P_ADDST และยอดยกมาครบแล้ว แถวใน P_ST เป็นการนับซ้ำ (ทบทวนอีกครั้งตอน UAT)
   - **ผู้ใช้เซ็นรายงานก่อน/หลัง (04, 04b, 04c) ก่อนทำ `05`**
   - `05` ลบซ้ำเป๊ะ · `05b` สำรองแถวขอบเขตไม่ชัด → `bak_P_ST_ambiguous_2569` · `05c` ลบแถวขอบเขตไม่ชัด (ด้วยคีย์ครบ 6 ช่องของแถวในตาราง `chk_P_ST_ambiguous_2569` เท่านั้น — ไม่ลบแถวอื่นแม้คีย์ใกล้เคียง)
   - `06` เก็บยอดหลังลบ · `07` รายชื่อสินค้าที่ยอดเปลี่ยน (ก่อน/หลัง/ผลต่าง ส่งออกเป็นรายงานเซ็น) · `08` ตรวจ ต้องได้ **0**
   - ย้อนกลับ: `INSERT INTO P_ST SELECT * FROM bak_P_ST_dup_2569` และ `INSERT INTO P_ST SELECT * FROM bak_P_ST_ambiguous_2569` (หรือคืนไฟล์จากข้อ 1)
4. **ตัดสต็อกครั้งเดียว ณ 31 ธ.ค. 2569** — เมนู ผลผลิต → "ตัดSTOCKสิ้นเดือน" → "ตัด STOCK ครั้งแรก" ใส่วันที่ 31/12/2569 กดปุ่ม "พิมพ์" **ครั้งเดียว** (ปุ่มตัดสต็อกจริงก่อนพิมพ์ ไม่มีหน้ายืนยัน) ไม่ต้องตัดย้อนรายเดือน (ปี 2569 ยังไม่เคยตัด) · ตรวจ: (ก) ยอดรวมทุกสินค้าก่อนตัดเท่ากับยอดรวมหลังตัด (เปิดตาราง `ต้นงวดP_ST` วันที่ 31/12/2569 รวม QTY เทียบกับรายงานก่อน) (ข) จำนวนแถวที่ย้ายเข้า P_ADDST เพิ่ม (ซ้อมปี 2569: ~16,000 แถว) (ค) P_ST เหลือยอดยกมา stock + รายการหลังวันตัด
5. **ตัดยอดแม่พิมพ์ครั้งเดียว ณ 31 ธ.ค. 2569** — เมนู แม่พิมพ์และรหัสเครื่องจักร → "ตัดSTOCKแม่พิมพ์" ใส่ช่วง 1/1/2569–31/12/2569 กด "พิมพ์" ครั้งเดียว · ⚠ Q-34: กลุ่มผ้าคลัทช์/ดิสเบรกอาจขึ้นกล่องถามค่า `QTY` — บันทึกว่าขึ้นกี่ครั้งและแจ้งทีมพัฒนาก่อนตอบ (ห้ามเดา) · ตรวจ: ยอดสะสมต่อแม่พิมพ์ ณ 31/12/2569 = ยอดยกมา 31/12/2568 + ใช้งานปี 2569 (RPT-15)
6. **รายงานตรวจยอด ส่งทีมพัฒนา** — ส่งออกเป็น CSV: ยอดยกมาต่อสินค้า (`ต้นงวดP_ST` วันที่ 31/12/2569) และยอดสะสมต่อแม่พิมพ์ (`ตันงวดการใช้งานของพิมพ์0` วันที่ 31/12/2569) + รายงานก่อน/หลังจากข้อ 3 (ข้อมูลจริง เก็บนอก git)
7. **เก็บสำเนาไฟล์สำหรับเทียบ + ย้ายรอบสุดท้าย** — Compact and Repair (ไฟล์เล็กลงประมาณครึ่งหนึ่ง) แล้วเก็บสำเนา `ผลผลิตและORDER_หลังปิดปี2569.accdb` ส่งทีมพัฒนาเพื่อ baseline เทียบ (#140) และย้ายข้อมูลรอบสุดท้าย ([full-run.md](full-run.md))

## ซ้อมซ้ำโดยทีมพัฒนา (ไม่ต้องกดปุ่ม)

บนสำเนาที่ตั้งชื่อให้มี `rehearsal`: `python -I -X utf8 tools/access-year-close/rehearse.py <สำเนา.accdb> <โฟลเดอร์ผลลัพธ์> --stock-cut 2026-08-31 --mold-cut 2026-01-01 2026-08-31` — รัน SQL ข้อ 3 และ query เดิมของมาโครข้อ 4–5 ผ่าน DAO พร้อมเวลา; ผลลัพธ์ที่มีรหัสจริงอยู่ในโฟลเดอร์ผลลัพธ์ (นอก git) · เทสต์อัตโนมัติของ SQL ข้อ 3 กับไฟล์จำลอง: `YearCloseKitTests`

## ยังไม่ได้ตรวจ

- การกดปุ่มในโปรแกรมจริง (ข้อ 4–5) และการลบ pd ซ้ำจากหน้าต่าง Query ของ Access: ซ้อมผ่าน DAO ด้วย SQL/query เดิมเท่านั้น เพราะเครื่องพัฒนาเปิดฟอร์ม/มาโครไม่ได้ (VBA เสีย) — ผู้ใช้ที่เปิดไฟล์ได้ต้องซ้อมตามรันบุ๊กบนสำเนาก่อนวันจริง
- ยอดแม่พิมพ์กลุ่มผ้าคลัทช์/ดิสเบรก (Q-34) ยังไม่ได้ซ้อม
- ผู้ใช้ตัดสินไว้แล้วให้ลบแถวขอบเขตไม่ชัด แต่ปีจริงต้องดูแถวตามขั้น 4b/4c ก่อนลบทุกครั้ง (อาจไม่ใช่แถวเดิมที่ซ้อม)
