# ด่านเทียบวัตถุดิบกับ Access และตาราง AC สำหรับตัดสินเปิดใช้ (ตั๋ว #271)

> ไม่มีข้อมูลจริงในเอกสารนี้ (ตัวเลขรวมจากการซ้อม เลขที่ใบสั่งซื้อมีในสเปคอยู่แล้ว) · เทียบ "ข้อมูลที่ย้ายมา" กับผลที่ query ของรายงานเดิมให้ ทีละแถว · รายการรายแถวมีชื่อผู้ขาย/วัตถุดิบจริง เก็บนอก git · แบบอย่าง: [`compare-gate.md`](compare-gate.md) (ORDER), [`cash-gate.md`](cash-gate.md) (เงินสดย่อย)

## วิธีทำ (รันซ้ำได้)

1. **สำเนา** — ทำสำเนา `วัตถุดิบ.accdb` (ปิด Access ที่เปิดไฟล์อยู่ — ห้ามเปิดไฟล์ที่ผู้ใช้ใช้งาน) ไว้นอก git เช่น `source/` · จดวันเวลาที่ทำ
2. **ย้ายข้อมูลลงฐานซ้อมชื่อเฉพาะ** บน dev SQL (ลงท้าย `Test`/`Uat`/`Dev` ห้าม `Lockte`/`LockteUat`/`LockteTheme`) — สร้างโครงด้วยเว็บแอป (`Lockte.Web -- reset-admin`) แล้วรันตามลำดับ:
   `--program employee --source พนักงาน.accdb` (ทะเบียนแผนก/พนักงานที่ใบขอซื้อและใบเบิกอ้าง) → `--program purch-master --source <สำเนา>` → `--program purch-history --source <สำเนา>` · ใส่ `--map` ถ้ามีตารางจับคู่ (`department`, `supplier-name`, `stock-employee` — มีชื่อจริง เก็บนอก git)
3. **ส่งออก baseline จาก Access** — `python -I -X utf8 tools/baseline/export_purch_baseline.py <สำเนา.accdb> <โฟลเดอร์ baseline> [--range รหัส,YYYY-MM-DD,YYYY-MM-DD] [--cut YYYY-MM-DD]`
   ต้องมี `pyodbc` และ ACE ODBC driver · สคริปต์ทำสำเนาชั่วคราวเองแล้วเปิดแบบอ่านอย่างเดียว · ~5 วินาที · ผลอยู่ใต้ `source/baseline/purch/` (ข้อมูลจริง ห้าม commit)
   ช่วงที่ส่งออก: ทุกปีตั้งแต่วันที่สั่งซื้อแรก, ทุกเดือนของ 24 เดือนล่าสุด, ตัวอย่าง AC-25/26 (ส.ค. 2026) และ AC-28 (ก.ย. 2026); วันตัดสต็อกทุกวันตั้งแต่ 2025-01-01 (ที่การย้ายโหลด)
4. **เทียบ** —

```
dotnet run --project src/Lockte.Migration -c Release -- --program compare-purch --baseline <โฟลเดอร์ baseline> ^
    --connection "<SQL ของฐานซ้อม>" --out <โฟลเดอร์รายงาน> [--map <ไฟล์จับคู่ที่ใช้ตอนย้าย>] [--rehearse-cut 2025-10-31 --confirm <ชื่อฐานซ้อม>]
```

   ไม่ใส่ `--rehearse-cut` = อ่านอย่างเดียว · ใส่ = **ซ้อมตัดสต็อก** ด้วยโปรแกรมใหม่ ณ วันนั้นสองครั้ง (AC-20) หลังเทียบยอดคงเหลือ (AC-18) และรายงานตัดสต็อกของข้อมูลที่ย้าย (AC-21) — เขียนลงฐาน จึงต้อง `--confirm` และไม่ยอมรันบนฐานที่ตั้งธง `Lockte.GoLive` · ซ้อมซ้ำต้องรัน `purch-history` ใหม่ก่อน (คืนสมุดสต็อกเป็นสภาพที่ย้าย)
   ได้ `purch-summary.md` (ตาราง AC + จำนวนความต่างตามที่มา), `purch-gate.csv`, `purch-compare.csv` (ต่อรายงานต่อช่วง), `purch-compare-details.csv` (**รายการรายแถว — ชื่อจริง นอก git**; คอลัมน์ "ที่มาของความต่าง") · exit code 0 = ผ่านทุกข้อที่ตรวจอัตโนมัติ
5. **ผู้ตัดสิน** — เจ้าของโครงการ + จัดซื้อ อ่าน `purch-summary.md`, รายการ "ยังไม่ทราบสาเหตุ" และ "ตรวจด้วยคน" · ใบขอซื้อ/ใบสั่งซื้อ (ระดับ A) ตรวจด้วยตาด้วย `tools/form-overlay`
6. **รอบสุดท้าย** — สำเนาใหม่ → ย้ายลงฐานจริง → ส่งออก baseline ใหม่ → เทียบอีกครั้ง (ไม่ใส่ `--rehearse-cut`) → ตั้ง Access เป็นอ่านอย่างเดียว → `--program mark-go-live` (ขั้นตอนเปลี่ยนระบบอยู่ในตั๋ว #272)
