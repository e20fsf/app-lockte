# ชุดข้อมูลปลอมของโปรแกรมวัตถุดิบ (#269)

ทีมพัฒนาและผู้ใช้ทดลองโปรแกรมวัตถุดิบด้วยข้อมูลที่ **สร้างจากสคริปต์ทั้งหมด** — ไม่มีชื่อผู้ขาย ที่อยู่ เบอร์โทร ราคา หรือรหัสจริงของบริษัท และไม่อ่านไฟล์ Access หรือไฟล์ใดเลย
(ผู้ใช้ตัดสินแล้วว่าข้อมูลจริงจาก Access ใช้ได้ในฐานแยกชื่อ แต่ห้ามเข้า git/สเปค — ชุดนี้เป็นทางเลือกที่ไม่เสี่ยง และเป็น fixture ของเทสต์)

## ใช้อะไรสร้าง

`Lockte.Web.Seeding.PurchFakeDataSeeder` เรียกผ่าน service ของโมดูลเอง (กติกาทุกข้อของโปรแกรมทำงาน และมีประวัติแก้ไขตามปกติ) ใช้ seed คงที่ (`20261029`) จึงได้ข้อมูลชุดเดิมทุกครั้ง

| มี | จำนวน / ลักษณะ |
|---|---|
| ผู้ขาย | 40 ราย รหัส `FS001`–`FS040` ชื่อ "ผู้ขายทดสอบ nnn" ครึ่งหนึ่งใช้ในการผลิต เครดิต 0/30/45/60 มี VAT และไม่มี |
| วัตถุดิบ | ราว 200 รายการ วัตถุดิบหลัก (`R`, `F`, `DC`, `SP` สปริง) และไม่ใช่หลัก (`B`, `E` รวม `E0054`, `T`, `MM`) และกลุ่มซื้อมาขาย `BA` `BR` `CH` `SL` `SP` |
| แผนก | ใช้แผนกในโมดูลองค์กรที่มีอยู่ (ถ้าไม่มี สร้าง "แผนกทดสอบ 1–3") ตั้ง prefix ใบขอซื้อ เช่น `D69-0001` |
| ใบขอซื้อ / ใบสั่งซื้อ | สั่งเต็ม สั่งบางส่วน ค้างรับ รับบางส่วน รับครบ ตรวจไม่ผ่าน VAT NO ยอด 5,000.00 พอดี ใบสั่งซื้อ 12 รายการ |
| การรับของ | มี LOT ผลตรวจ (ผ่าน/ไม่ผ่าน) และใบรับรอง |
| สต็อก | ใบเบิก ยอดติดลบ 1 รหัส (ยกมาติดลบ) ตัดสต็อกแล้ว 1 งวด (30 มิ.ย. 2569) |
| ผลประเมินผู้ขาย | ไตรมาสที่ 2 ปี 2569 (เม.ย.–มิ.ย.) |

## รันบนเซิร์ฟเวอร์ทดสอบ (คำสั่งเดียว ลบแล้วสร้างใหม่)

```powershell
$env:LOCKTE_UAT_SQL = 'Server=...;User Id=...;Password=...;TrustServerCertificate=True'
.\tools\uat\Reset-PurchFake.ps1 -Database LockteMatUat -AdminPassword 'ตั้งรหัสชั่วคราวเอง'
```

สคริปต์ปฏิเสธถ้าชื่อฐานไม่ขึ้นต้น `Lockte` และลงท้าย `Uat`/`Test`/`Dev` ถ้าเป็น `Lockte` เอง หรือฐานตั้งธงเปิดใช้งานจริงแล้ว (`Lockte.GoLive`) · ใช้ชื่อฐานแยกจาก `LockteUat` (ข้อมูลพนักงาน/ORDER) เพราะสคริปต์ลบฐานก่อนสร้างใหม่

เติมเข้าฐานที่สร้างโครงไว้แล้ว (ไม่ลบ) ได้ด้วย `dotnet run --project src\Lockte.Web -- seed-purch-fake` · ฐานที่มีชุดนี้แล้วจะถูกปฏิเสธ (ไม่เติมซ้ำ)

## ในเทสต์

`PurchFakeDataTests` สร้างฐานของตัวเองแล้วเติมชุดนี้ ตรวจว่าครบและมีกรณีขอบที่ AC ใช้ — เทสต์อื่นที่ต้องการข้อมูลชุดนี้สร้าง `PurchFakeDataSeeder` ด้วย scope ของตัวเองแบบเดียวกัน
