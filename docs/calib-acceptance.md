# สอบเทียบ — ด่านตัดสินเปิดใช้ (AC-01…14) และรายการตรวจด้วยตา

ตั๋ว #213 · ที่มาของเกณฑ์: `specs/สอบเทียบ/acceptance.md` · โปรแกรมนี้ไม่มีการคำนวณ จึงเทียบ**ข้อมูลที่พิมพ์** ผลจริงของการเทียบมีชื่อบุคคลและหมายเลขเครื่อง → เก็บใต้ `source/` นอก git

## ขั้นตอน (รันซ้ำได้)
1. ส่งออก baseline จากสำเนา Access (ชื่อไฟล์ต้องมี `copy`): `python -I -X utf8 tools/baseline/export_calib_baseline.py "<source>\สอบเทียบ-copy.accdb" "<source>\baseline-calib"`
2. ย้ายข้อมูลเข้าฐานทดสอบ (ตั๋ว #209) แล้วโหลดรูป JIG (#200): `Lockte.Migration --program calib … --jig-images <โฟลเดอร์>`
3. เทียบ: `Lockte.Migration --program compare-calib --baseline "<source>\baseline-calib" --connection "<SQL ของฐานทดสอบ>" --out "<โฟลเดอร์นอก repo>"`
   ได้ `calib-gate.csv` (ด่าน), `calib-compare.csv` (ต่อชนิด), `calib-compare-details.csv` (ทุกค่าที่ต่าง พร้อมประเภทและยอมรับ/ไม่ยอมรับ), `calib-summary.md` · exit code 1 ถ้ามีข้อที่ไม่ผ่าน

ค่าที่ต่างและ**ยอมรับ** (นับและแสดงเหตุผลทุกแถว ไม่ซ่อน): วันที่แก้ปีตามกฎ (AC-02, ผู้ใช้ยืนยัน Q-08) · ปีนอกกฎที่เว้นว่างรอคำตัดสิน · ผู้สอบเทียบ/แผนก/เครื่องจักรที่ยังไม่ผูกกับ hr/org (อยู่ในรายงาน DQ) · หน่วยว่างของตัวควบคุมอุณหภูมิที่เติม `°C` · แถวที่หมายเลขว่าง/ซ้ำซึ่งไม่ย้าย · ข้อความ `DC (D02)` ที่ประกอบจาก org เทียบแบบไม่สนช่องว่าง — นอกนั้นที่ต่างทำให้ไม่ผ่าน
