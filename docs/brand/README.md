# โลโก้บริษัท

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `logo.svg` | ไฟล์หลัก — วาดใหม่จาก `logo.png` (แดง `#FF0000` พื้นโปร่ง) คมทุกขนาด |
| `logo.png` | ต้นฉบับที่ผู้ใช้ส่งมา 175×138 px — เก็บไว้อ้างอิง |

ตำแหน่งที่ใส่ (ตัดสินใน [ตอบคำถามค้างของผลผลิตและORDER ก่อนส่งต่อ to-spec](https://github.com/e20fsf/app-lockte/issues/28), ใช้ทุกโปรแกรม):
- ในโปรแกรม: หน้า login, แถบหัวทุกหน้า, เมนูหลัก, favicon
- รายงาน/เอกสารพิมพ์: **เฉพาะฉบับที่ระบบเดิมมีโลโก้** — ไม่เพิ่มในฉบับที่เดิมไม่มี (เอกสารออกนอกบริษัทต้องตรงรูปแบบเดิม)

ถ้าได้ไฟล์ต้นฉบับความละเอียดสูงจากบริษัท ให้แทน `logo.svg` ด้วยไฟล์นั้น

ระบบเว็บใช้สำเนาที่ `src/Lockte.Web/wwwroot/brand/logo.svg` (static web assets ของ ASP.NET Core ไม่เสิร์ฟไฟล์นอก `wwwroot`) — เปลี่ยนโลโก้ให้แก้ทั้งสองไฟล์ เทสต์ `BrandLogoTests` ตรวจว่ายังตรงกัน
