# Matt Pocock skills (vendored)

สำเนา skill จาก plugin `mattpocock-skills` เวอร์ชัน **1.2.3** ([github.com/mattpocock/skills](https://github.com/mattpocock/skills), MIT — ดู [LICENSE-mattpocock-skills](LICENSE-mattpocock-skills)) เก็บไว้ใน repo เพื่อให้เครื่องอื่นที่ clone repo นี้ใช้ได้ทันทีโดยไม่ต้องติดตั้ง plugin

เป็นชุดที่ plugin เผยแพร่ (ตาม `.claude-plugin/plugin.json`) 25 ตัว — ไม่รวมโฟลเดอร์ `in-progress/` และ `misc/` ของต้นฉบับ:

- engineering: ask-matt, code-review, codebase-design, diagnosing-bugs, domain-modeling, grill-with-docs, implement, improve-codebase-architecture, prototype, research, resolving-merge-conflicts, setup-matt-pocock-skills, tdd, to-spec, to-tickets, triage, wayfinder, wizard
- productivity: grill-me, grilling, handoff, teach, to-questionnaire, wait-what, writing-for-agents

ไม่ได้แก้เนื้อหา คัดลอกตรงจากต้นฉบับ ค่าที่ skill เหล่านี้อ่านของ repo นี้อยู่ใน [`docs/agents/`](../../docs/agents/) (issue tracker, triage labels, domain docs)

เรียกใช้ด้วยชื่อตรง ๆ เช่น `/wayfinder`, `/grilling` (เครื่องที่ติดตั้ง plugin ด้วยจะเห็นทั้ง `/wayfinder` และ `/mattpocock-skills:wayfinder` — เนื้อหาเดียวกัน)

**อัปเดต:** คัดลอกโฟลเดอร์ skill จากเวอร์ชันใหม่ทับ แล้วแก้เลขเวอร์ชันในไฟล์นี้
